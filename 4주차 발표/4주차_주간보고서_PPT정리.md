## 한눈에 보기

- **최종 기본안**: 밀폐형 STLCD + 직교배치(X·Y) + 준능동(Groundhook) 밸브
- 밀폐형은 8개 기록 모두 물기둥 이동 한계 이내 (개방형은 7/8 초과)
- 직교배치는 방향 변화에 따른 성능 손실이 작고, 원환형과 성능 차이가 거의 없음(9.83% vs 9.82%)
- 준능동 밸브는 수동형 대비 평균 +1.1%p, 샌퍼난도(M6.6) 정착시간 약 25% 단축
- 공압·펌프 재튜닝·회전형은 **조건에 따라 오히려 악화** → 원인 분리 검증 필요
- 계산 검증은 통과, **Simulink 구현은 다음 단계**

## 01. 장치 원리와 비교 조건

### 물의 움직임을 조절하는 방법 (슬라이드 4)
STLCD = 물기둥과 밀폐 공기실이 함께 작용하는 TLCD

| 방식 | 구분 | 원리 |
|---|---|---|
| 밸브 | 준능동 | 물의 흐름 저항을 바꿔 에너지 소산 조절 |
| 공압 | 능동 | 공기압 차이로 물기둥에 힘을 가함 |
| 펌프 | 재튜닝 | 수위를 바꿔 장치 고유진동수 조정 |

→ 기존 조합(밸브+펌프)과 대체 후보(공압)를 나란히 비교

### 비교 대상 건물 모델 (슬라이드 5)
- 6층 전단건물, 층별 질량·강성 동일 가정 (단순화 모델)
- 1차 고유진동수 **0.872 Hz** (주기 약 1.15초)
- TLCD 설계 기준 질량 **1,382.1톤**, 액체질량 X축 0.5% + Y축 0.5% = 총 1.0% (축당 약 6.91톤)
- 3층 조건은 치수 제약(물 양·이동 공간) 때문에 6층으로 전환
- 참고 문헌: Acta Mechanica (2024) — 단주기 저층 구조물은 TLCD 튜닝 자체가 어려움 / JIPR (2026) — 6층 RC + 밀폐형 STLCD 설계값 공개

### 시험별 입력과 평가 지표 (슬라이드 6)
공통: PGA 0.2g, 계산 간격 0.005초

| 시험 | 기록 수 | 주요 평가 |
|---|---|---|
| 개방형·밀폐형 / 준능동 | 8개 | RMS 변위·스트로크·정착시간 |
| 직교배치 / 원환형 | 동시관측 2성분 6개 | X·Y 합성 최대변위 |
| 공압 / 펌프 재튜닝 | 4개 / 8개 | RMS 변위 저감률 |

- 저감률 = (1 − 제어 응답 ÷ 무제어 응답) × 100% (양수 개선, 음수 악화)
- Peak = 가장 큰 순간 변위 / RMS = 전체 구간 변위 크기
- 서로 다른 입력에서 나온 수치(예: 29% vs 13%)는 직접 우열 비교하지 않음

## 02. 기본 장치와 배치 선정

### ① 개방형 vs 밀폐형 (슬라이드 8)

| 평가 항목 | B 개방형 | C 밀폐형 |
|---|---|---|
| 스트로크 한계 초과 | 7 / 8개 | 0 / 8개 |
| 최대 스트로크 이용률 | 312.7% | 81.9% |
| 평균 RMS 변위 저감률 | 22.1% | 10.0% |

개방형은 저감률이 더 커 보이지만 이동 한계를 넘는 조건이 대부분이라 그대로 채택하기 어렵다 → **밀폐형 선택**. (압력·설치 공간은 추가 검토 필요)

### ② 준능동 밸브 (슬라이드 9)
- 평균 RMS 저감률 10.0% → 11.1% (**+1.1%p**), 8개 기록 모두 수동형 이상
- 샌퍼난도(M6.6) 정착시간 52.1초 → 39.1초 (**13초, 약 25% 단축**)
- 정착시간 기준: 무제어 피크의 30% 이하로 재상승 없이 내려가는 시점
- 주에쓰오키(M6.6)는 준능동도 음의 저감률 → 밸브만으로 모든 조건 해결은 아님

### ③ 직교배치 (슬라이드 12) — 동시관측 6개 기록, 총 액체질량 동일
- 6개 모두 합성 최대변위 저감률 개선
- 샌퍼난도(M6.6): 6.5% → 12.7% / 만질(M7.4): −0.6% → 17.3%
- 비편심 건물 가정, X·Y 독립 계산 (모든 지진·모든 각도의 우위를 뜻하지는 않음)

### ④ 질량 분할 후 감쇠 재조정 (슬라이드 10)
질량을 절반씩 나눈 뒤 감쇠를 그대로 두면 Y축 스트로크 한계 초과 → 오리피스 손실계수 ξ를 **0.149 → 0.50**으로 조정

| 지진 | Y축 스트로크 이용률 |
|---|---|
| 샌시미언(M6.5) | 150.2% → 99.2% (여유 작음) |
| 임페리얼밸리(M6.5) | 119.7% → 80.3% |

ξ=0.50을 실제 오리피스 개구비로 구현 가능한지는 추가 확인 필요.

### ⑤ 1기 vs 2기 — 입사각 의존성 (슬라이드 11)
샌시미언(M6.5) 단일 파형을 회전 투영한 결과:
- 1기: 0°에서 43.48%로 최고, **90°에서 0.00%**
- 2기(직교): 모든 각도에서 약 **29%** 유지 (변동폭 약 0.55%p)
- "대각선에서 크게 나빠질 것"이라는 예상은 틀렸음
- 결론: 최고 성능 일부를 포기하는 대신 방향에 따른 손실을 줄인 선택

### ⑥ 직교배치 vs 원환형 (슬라이드 13)
- 처음엔 원환형 평균 14.6%로 우세해 보였으나, 두 축에 전체 질량비를 각각 적용한 **가정 오류**였음
- 합성 유속 기반 결합감쇠 반영 + 질량비 매칭 후 재계산:

| | 직교배치 | 원환형 |
|---|---|---|
| 평균 저감률 | 9.83% | 9.82% |
| 개별 차이 | 최대 0.03%p | |

→ 뚜렷한 이득이 없어 구조가 단순한 **직교배치 선정**. (실제 원환형 유체 거동 전체를 검증한 것은 아님)

## 03. 제어 방법의 효과와 한계

### 공압 응답 속도 (슬라이드 15) — Kp = 2.0, RMS 저감률

| 지진 | 5 ms (빠름) | 500 ms (느림) |
|---|---|---|
| 샌퍼난도(M6.6) | −155.6% | +1.4% |
| 임페리얼밸리(M6.5) | −41.3% | +6.4% |
| 샌시미언(M6.5) | +27.7% | +32.9% |
| 만질(M7.4) | +28.2% | +24.5% |

- 샌퍼난도 −155.6% = 무제어 RMS의 약 2.56배
- "빠를수록 항상 좋다" 가설은 성립하지 않음 (발산 여부·원인은 확정 불가)

### 펌프 재튜닝 (슬라이드 16)
- 가정: 건물 고유진동수 8% 저하 (장치 목표 0.872 → 약 0.802 Hz), 밸브 제어는 전후 동일
- 8개 중 **4개 개선 / 4개 악화**, 평균 **−2.2%p**
- 진동수 일치만으로 개선이 보장되지 않음. 밸브와의 상호작용은 가능한 원인이나 가설

### 회전형 탐색 (슬라이드 17) — 샌시미언(M6.5), 준정적 회전 근사
- 1~30°/s 구간: 15.2~15.6% (같은 입력의 직교배치 13.2%)
- 고속으로 갈수록 저하 → **근사 한계**, 회전 로직만의 결함으로 단정 불가
- 관성·회전 결합항 등 근사 영향과 추적 로직을 함께 점검 후 추가 검증

### 최종 선정 (슬라이드 21)
**직교배치 + 준능동 밸브를 기본안으로 유지**
- 밀폐형: 8개 단방향 기록에서 이동 한계 이내
- 직교배치: 각도별 변동이 작고 원환형 대비 이득 차이 작음
- 준능동 밸브: 평균 +1.1%p, 정착시간 약 25% 단축
- 공압·펌프·회전형은 효과가 달라지는 조건과 원인을 더 확인
