# TLCD 능동제진 시뮬레이션 (MATLAB)

건물-TLCD 연성계를 Newmark-β 법으로 시간적분하고, 액추에이터 포화와 제어 지연의
영향을 정량화합니다.

**MATLAB R2026a에서 실행·검증 완료.**

## 중요 — 이 PC에는 툴박스가 없습니다

`ver`로 확인한 결과 **MATLAB 본체와 Simulink만** 설치되어 있습니다.
따라서 아래 함수는 쓸 수 없고, 이 코드는 전부 기본 함수로만 작성했습니다.

| 못 쓰는 함수 | 필요한 툴박스 | 대체 방법 |
|---|---|---|
| `tf`, `lsim`, `ss` | Control System | 필터 미분방정식 직접 적분 |
| `rms` | Signal Processing | `sqrt(mean(x.^2))` |

새 코드를 추가할 때도 툴박스 함수를 쓰지 마세요.

## 실행

```matlab
verify_model('3F')                        % 4단계 모델 검증
main_stage1('10F','elcentro',0.2)         % 1단계 3자 비교
main_stage2('10F')                        % 2단계 성능 절벽 탐색
main_stage3('10F','pohang',0.1)           % 3단계 제어 지연
```

그래프는 `fig/`에 PNG로 저장됩니다.

## 애니메이션 — 눈으로 보기

```matlab
animate_tlcd                                    % 화면에서 바로 재생
animate_tlcd('10F','pohang',0.2)                % 조건 지정
animate_tlcd('10F','pohang',0.2, struct('save',true))   % MP4로 저장
```

화면 구성
- **왼쪽**: 무제어 건물과 TLCD 건물이 나란히 흔들립니다
- **오른쪽**: U자관 확대 패널. 물이 좌우로 오르내리고, 빨간 한계선에 닿으면
  물이 **빨갛게 변하며 "포화!"** 가 뜹니다
- **아래**: 최상층 변위 시간이력. 검은 점이 현재 시각을 따라갑니다

옵션

| 필드 | 기본값 | 의미 |
|---|---|---|
| `save` | false | true면 `fig/anim_*.mp4` 저장 |
| `scale` | 15 | 변위 확대배율 (실제 변위는 너무 작아 안 보임) |
| `Tshow` | 15 | 보여줄 시간 [s] |
| `fps` | 25 | 초당 프레임 |
| `snapshot` | 없음 | 특정 시각의 정지 이미지 PNG 저장 (예: `[3.0 7.5]`) |

발표용 정지 이미지를 뽑으려면:

```matlab
animate_tlcd('10F','pohang',0.2, struct('save',true,'snapshot',[5.6 7.52]))
```

> U자관은 **실제 비율이 아닙니다.** 실제로는 건물 높이 9 m에 관 높이 0.5 m라
> 비율대로 그리면 물 움직임이 보이지 않습니다. 확대 패널에 그 사실을 명시해
> 두었으니 발표 때도 그대로 설명하시면 됩니다.

## 지배방정식

```
(Ms + mf·e·e')·x'' + α·mf·e·xf'' + Cs·x' + Ks·x = -(Ms + mf·e·e')·r·ag
 α·mf·e'·x''  + mf·xf'' + ½ρA·ξ·|xf'|·xf' + 2ρAg·xf = -α·mf·ag
```

비선형 감쇠항 때문에 매 스텝 고정점 반복(최대 6회)으로 수렴시킵니다.
포화는 하드스톱 페널티(강성 `k_stop × kf`)로 모델링합니다.

## 핵심 발견 1 — 3층은 물리적으로 불가능합니다

`main_stage1('3F', ...)` 실행 결과:

```
1차 진동수 1.200 Hz
물기둥 전체길이 L : 0.359 m
수직부 높이   h   : 0.036 m     <-- 스트로크 한계 3.6 cm
단면적       A    : 25.6 m^2    <-- 원형 환산 직경 5.71 m
RMS 저감률        : 0.5%
물기둥 사용률     : 1.27 (포화)
```

지름 5.7 m 관에 물이 3.6 cm — 감쇠기가 아니라 수영장입니다.
ω = √(2g/L)에서 주기를 짧게 하려면 L을 줄여야 하는데, 질량비를 유지하려면
단면적이 폭발적으로 커지기 때문입니다.

**이것은 Acta Mechanica(2024)와 J. Infrastruct. Preserv. Resil.(2026)이 지적한
"단주기 저층 건물의 TLCD 튜닝 난점"을 수치로 재현한 것입니다.**

10F preset(0.5 Hz)에서는 L=2.06 m, h=20.6 cm, RMS 저감 **33.7%** 로
문헌값 범위(23~35%)에 정확히 들어옵니다.

## 핵심 발견 2 — 성능 절벽이 지진마다 다릅니다

`main_stage2('10F')` 결과 (스트로크 한계 20.6 cm):

| 지진 | 최대 저감률 | 포화 시작 | 절벽 위치 | 절벽 후 |
|---|---|---|---|---|
| 경주형 (고주파) | 40.8% | 0.375g | 0.50g | 32.1% |
| **포항형 (공진)** | **44.0%** | **0.075g** | **0.15g** | **7.8%** |
| El Centro형 | 44.2% | 0.075g | 0.20g | 26.5% |

**포항형이 압도적으로 취약합니다.** 지배 주기가 건물과 겹쳐 공진하므로
물기둥이 0.075g에서 이미 한계에 닿고, 0.45g에서는 저감률이 7.8%까지 무너집니다.

경주형은 반대로 주파수가 안 맞아 물기둥이 잘 움직이지 않고,
그 덕에 포화가 늦게 옵니다(0.375g).

→ **2주차 발표 15번 슬라이드의 가설이 검증되었습니다.**

## 핵심 발견 3 — 제어 지연은 예상보다 영향이 작습니다

`main_stage3('10F','pohang',0.1)` 결과:

| 지연 | RMS 저감률 |
|---|---|
| 0 ms | 39.6% |
| 50 ms | 38.4% |
| 100 ms | 37.0% |
| 200 ms | 37.4% |

**발산이 일어나지 않습니다.** 200 ms에서도 성능 저하가 2.6%p뿐입니다.
문헌의 *"준능동 시스템은 본질적으로 안정하므로 지연에 의한 불안정은 발생하기
어렵다"* 는 견해와 일치합니다.

또한 경주형에서는 현재 on-off 제어 법칙이 고정 오리피스보다 **나쁩니다**(-7.2%p).
고주파 가진에 이 법칙이 맞지 않습니다 — 제어 법칙 개선이 필요합니다.

## 다음 할 일

1. **건물 모델 결정** — 3층을 유지하려면 TLCD가 성립하지 않습니다.
   6~10층으로 올리거나, "왜 저층에서 안 되는가"를 결과로 삼아야 합니다. (W3~4)
2. **실측 지진파 교체** — 현재는 합성파입니다. 기상청 경주·포항 기록과
   PEER NGA-West2의 El Centro로 반드시 교체하세요.
3. **제어 법칙 개선** — 현재 on-off 그라운드훅은 고주파에서 역효과입니다.
   클립트-옵티멀 등 다른 법칙을 검토하세요. (W11)
4. **연구축 ② 재검토** — 지연 영향이 작으므로, "발산"이 아니라
   "성능 저하율"과 "제어 법칙 적합성"으로 프레임을 조정하는 편이 낫습니다.

## 주의

- `gen_ground.m`의 지진파는 **합성 대체파**입니다. 보고된 지배 주기와 지속시간만
  재현한 것으로, 실측 기록이 아닙니다. 논문에는 쓸 수 없습니다.
- 단면적 A가 비현실적으로 크게 나오면 질량비 μ를 낮추거나 건물 주기를 늘리세요.
- `p.stroke_limit`으로 기하학적 한계보다 더 좁은 제약을 걸 수 있습니다.
