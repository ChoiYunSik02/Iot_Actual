## 3. 파트 01 — 수동 vs 준능동 밸브 (4장)

### 슬라이드 구성
| 슬라이드 | 내용 |
|---|---|
| 1-1 방식 구분 | 수동(고정 오리피스) / 준능동(가변 오리피스: on-off·연속) / 능동(공압). 비교 항목: 외부 에너지, 안정성, 응답속도, 고장 시 동작(fail-safe). 준능동은 에너지를 넣지 않아 본질적으로 안정 → 4주차 공압 −155% 악화와 연결 |
| 1-2 제어 규칙 | Groundhook(Δ-DBG, 현재 사용), Skyhook, 단순 on-off. 어떤 신호로 밸브를 여닫는지 그림 |
| 1-3 Ocean Eng. 기준 비교 + 시험 | 아래 비교표와 시험 1~4 |
| 1-4 밸브 구현 가능성 | ξ → 차단율 환산으로 "ξ=0.50을 실제 밸브로 만들 수 있나" 답변, 밸브 개폐시간(ms) |

### 기준 논문: Mendes et al., Ocean Engineering 326 (2025) 120859
`논문/07_OceanEng2025_offshore_groundhook.pdf` — 원문 전체 확인함

| 항목 | 논문 내용 |
|---|---|
| 대상 | 해상풍력 타워 5, 10, 15 MW. 구조 감쇠 1% |
| 하중 | 바람(Kaimal) + 파도(JONSWAP) 랜덤 하중, 풍속 조건마다 100케이스 평균 |
| TLCD | μ = 2%, 길이비 B/L = 0.30 / 0.30 / 0.27 (타워 내부 설치 제약), 튜닝비 0.98 |
| 밸브 표현 | 오리피스 차단율 ψ → 손실계수 ξ(ψ) 환산식 (식 2, Wu et al. 2005) |
| 수동 밸브 | 차단율 50% 고정 (조사한 값 중 가장 효율적) |
| 준능동 밸브 | 두 상태 on-off. 1자유도 예비해석: 최대 감쇠 = 최적 수동값 × 2, 최소 = × 0.6 |
| 제어 규칙 | Δ-DBG: 구조물 변위 증분 × 물기둥 속도 ≤ 0 → 최대 감쇠, > 0 → 최소 감쇠 |
| 차단율 조합 탐색 | ψ_max 55~80% × ψ_min 5~45% 격자 (표 3~5). 스트로크 한계 초과 조합은 "−" 처리, ψ_max 85·90%는 제외 |
| 최적 조합 | 5 MW 55/5%, 10 MW 70/5%, 15 MW 60/5%. **ψ_min(최소 감쇠)이 결과에 더 큰 영향** |
| 성능 (운전 중) | 수동 약 25% → 준능동 31.4 / 32.6 / 31.7% (RMS 변위 저감) |
| 성능 (정지) | 준능동 30.4 / 30.4 / 31.6%, 수동과 차이 1~5%로 줄어듦 |
| 결론 | 하중이 약하거나 설계 조건을 벗어나면 준능동 ≈ 수동 → 차단율 고정이 낫다 (에너지 불필요) |

### 우리(4주차)와 비교
| 항목 | Ocean Eng. 2025 | 우리 |
|---|---|---|
| 하중 | 정상(stationary) 랜덤 | **과도 지진** 8개 기록, PGA 0.2g |
| μ | 2% | **0.5% × 2축** |
| B/L | 0.27~0.30 | 0.6 (2.4 / 4.0 m) |
| 형식 | 개방형, 단방향 | **밀폐형, X·Y 직교** |
| 준능동 이득 | 수동 대비 상대 약 10~20% | 10.0 → 11.1%, **상대 약 11%** |
| 밸브 표현 | 차단율 ψ (실제 밸브 개도) | ξ 값만 (0.149, 0.50) |
| 지연·개폐시간 | 고려 안 함 | 우리 연구축 |

**발표 포인트:** +1.1%p는 작아 보이지만 수동 대비 **상대 향상률은 논문과 같은 수준**.
절대값 차이는 μ(2% vs 축당 0.5%)와 하중 종류 때문이라고 설명.

### 파트 01 시험 (논문 방식 따라 하기)
1. **ξ ↔ 차단율 환산** — 식 (2)로 ξ = 0.149, 0.50을 차단율로 변환 → 4주차 미검증 항목 해결.
   ※ PDF 텍스트 추출에서 식이 깨졌으므로 원문 보고 옮길 것
2. **ψ_max × ψ_min 격자 탐색** — 논문 표 3~5 형식, 스트로크 초과 칸 "−".
   "지진에서도 ψ_min이 더 중요한가"가 논문과 직접 비교되는 결과
3. **초기값 재설정** — 최대 = 최적 수동 × 2, 최소 = × 0.6.
   ※ 4주차 코드가 폴더에 없어 우리가 쓴 최대·최소값은 확인 못 함 → 코드 확인 필요
4. **하중 크기별 이득** — PGA 0.05~0.5g. 논문의 "하중 약하면 준능동 ≈ 수동"이 지진에서도 성립하는지 → 포화 연구축과 연결
5. **차별점** — 논문에 없는 것: 지진 과도 응답, 양방향, 밀폐형, 밸브 지연·개폐시간

| 슬라이드 | 내용 |
|---|---|
| 2-1 파라미터 비교표 | PLOS ONE 2022 (μ 5%, γ 0.98, α 0.8, 저감 23~35%), JIPR 2026 (6층, 밀폐형), Ocean Eng. 2025 (위 표), 우리 (μ 1%, 저감 10~11%) |
| 2-2 같은 조건에서 재현 | 우리 모델에 논문 파라미터(μ=5% 등)를 넣어 재실행 → 저감률이 낮은 원인이 μ인지 모델인지 분리. "입력이 다른 수치끼리는 직접 우열 비교 금지" 원칙 유지 |
| 2-3 μ·γ·ξ 스윕 | **스트로크 한계 이내** 조건 하 최적 조합 히트맵. 예: "μ 2%면 X%, 대신 물 Y톤 추가" |

## 5. 파트 03 — 지진 예측 선제 제어 (6장, 핵심)

### 슬라이드 구성
| 슬라이드 | 내용 |
|---|---|
| 3-1 개념 | 조기경보 수신 또는 현장 센서 P파 감지 → S파 도착 전 **리드타임** 동안 액추에이터 사전 동작 |
| 3-2 리드타임 현실성 | S−P 시간차 ≈ 진앙거리 ÷ 8 (초). 50 km ≈ 6초, 100 km ≈ 12초, 500 km ≈ 60초. 포항처럼 진원이 가까우면 사실상 0초(경보보다 흔들림이 먼저). **"1분 전"은 먼 지진 시나리오**임을 먼저 짚기. 기상청 경보 발표 소요시간은 기상청 자료로 확인 |
| 3-3 리드타임별 가능한 일 | 밸브(ms) 즉시 프리셋 / 공압 수 초 내 공기실 압력 설정 / 펌프(수십 초~분)는 **리드타임이 있어야만 의미** → "느린 액추에이터를 예보로 보완" |
| 3-4 시험 설계 | 리드타임 0, 5, 10, 15, 30, 45, 60초 × 전략 4종 × 8개 기록. 펌프 유량 한계 Δh = Q·T/A. 지진 기록 앞에 T초 정지 구간 + t=0 예보 트리거 |
| 3-5 리드타임-저감률 곡선 | "몇 초면 충분한가" → IoT 통신·경보 요구조건 |
| 3-6 예보가 틀리면? | 예측 규모·지배주기 ±오차. 4주차 재튜닝 8개 중 4개 악화 → 틀린 예보로 움직이면 손해 가능. **허용 예보 오차 범위** 제시 = 가장 큰 어필 포인트 |

- 경보 시각 = S파 도착(|지반가속도| 최초 0.05g 초과, Cremen 2022 기준) − 리드타임

- 전략: S0 없음, S1 밸브 프리셋(0.05 s), S2 펌프 재튜닝(30 s), S3 밸브+펌프, S4 밸브+공기압(3 s)
- 액추에이터 속도(3 s, 30 s)는 **가정값**
- 입력은 **합성 대체파 3종** (경주·포항·El Centro 특성) — 실기록 교체 필요

### 결과 2 — 리드타임별 성능 (그림 1·2, 정확한 예보, 기록 3개 평균)
| 조건 | S0 저감 / 스트로크 | 밸브 프리셋(S1) | 펌프(S2) | 밸브+펌프(S3) |
|---|---|---|---|---|
| A, 0.6g | 4.7% / **1.07 (한계 초과)** | 5.2% / **0.72** | 변화 없음 | 5.2% / 0.72 |

- 밸브는 **리드타임이 필요 없음** — 흔들림 뒤 3초에 경보가 와도 효과 유지 (= 정보 효과)
- 펌프는 B에서만 이득(+1.6~3.1%p), 혼자서는 포화를 못 막음 → **밸브+펌프 조합이 최선**
- 0.2g에서는 모든 전략 이득 0 (기본 설정이 이미 0.2g 최적)

### 결과 3 — 펌프 속도 vs 필요 리드타임 (그림 5, 핵심 그림)
| 펌프 전 범위 이동 시간 | 30 s | 60 s | 120 s | 300 s |
|---|---|---|---|---|
| 필요 리드타임 (최대 이득의 90%) | **2 s** | **10 s** | **30 s** | **90 s** |

→ **필요 리드타임 ≈ 펌프 전 범위 시간 × 0.3** (이번 조건에서 재튜닝 폭이 범위의 약 1/3이기 때문).
→ "1분 전에 움직여야 하나?"의 답: **펌프가 느릴수록 그렇다.** 리드타임 요구조건은 액추에이터 속도로 정해짐 = IoT 요구조건.

### 결과 4 — 예보 오차 (그림 3, S3, B, 0.6g)
- 과소 예측(×0.5)에서도 S0 대비 +1.8~1.9%p, 정확(×1) +2.1~2.3%p → 오차에 둔감
- ※ 설정표 범위가 0.6g까지라 과대(×2 = 1.2g)는 0.6g로 잘려 정확과 같게 나옴 → 표 범위 확장 필요

### 발표 핵심 메시지
1. 예측 제어의 이득은 두 종류: **정보 효과(밸브, 리드타임 불필요)** 와 **시간 효과(펌프, 리드타임 필요)**
2. 밸브 프리셋은 강진에서 **물기둥 포화를 막는 안전장치** 역할
3. **필요 리드타임은 펌프 속도에 비례** — 30초 펌프면 수 초, 5분 펌프면 1분 이상
4. 리드타임 현실성 표와 합치면: 진원 근처(포항형)는 밸브만, 원거리(수도권 등)는 펌프까지 가능
