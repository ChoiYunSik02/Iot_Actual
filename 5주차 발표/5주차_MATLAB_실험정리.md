## 1. 왜 이 실험을 했나

4주차 교수님 피드백:
> 지진이 처음 들어왔을 때부터 5초, 10초, 15초 … 1분 미리 움직이는 기능을 넣어서,
> 지진 예측 센서 혹은 지진 예보를 받고 제어를 넣어보기

그래서 확인하려던 질문은 두 가지다.
1. 경보를 받고 미리 움직이면 성능이 좋아지는가?
2. 좋아진다면 **몇 초 전**에 경보가 와야 하는가? (= IoT 통신 요구조건)

## 4. 제어 방식 — 경보가 오면 일어나는 일

```
경보 수신 ──► 예측 PGA 확인 ──► 설정표에서 최적 (ξ, γ) 찾기 ──► 액추에이터가 속도 한계 안에서 이동 ──► 흔들림 중 밸브 Δ-DBG
```

- **경보 시각** = S파 도착 − 리드타임
  - S파 도착: 한국 기록은 진앙거리 ÷ 3.5 km/s, El Centro는 |ag|가 처음 0.05g를 넘는 시각
- **설정표**: 예측 PGA별로 "물기둥 한계 이내에서 저감률이 최대인" 밸브 감쇠 ξ와 튜닝비 γ를 미리 계산
- **액추에이터 속도** (범위 전체를 움직이는 데 걸리는 시간)

| 액추에이터 | 바꾸는 것 | 속도 | 근거 |
|---|---|---|---|
| 밸브 | 감쇠 ξ | 0.05 s | ms 단위 |
| 공기압 | 튜닝비 γ | 3 s | **가정** |
| 펌프 | 튜닝비 γ | 30 s | **가정** |

## 5. 실험 목록

### 실험 1 — 설정표 만들기 (`w5_lookup.m`)
- 예측 PGA 0.1~1.2 g (12단계) × 감쇠 ξ 0.25~64 (9단계) × 튜닝비 γ 0.86~1.04 (10단계) × 기록 3개
- 시나리오 2개: **A 강성 일정**, **B 강진 시 강성 저하(가정: 0.2g 3%, 0.4g 9%, 0.6g 15%)**
- 계산 약 40분 (실측 기록, 60 s 길이)

### 실험 2 — 본 실험 (`w5_main.m`, 총 2,430회)

| 변수 | 값 |
|---|---|
| 리드타임 | −3, 0, 2, 5, 10, 15, 30, 45, 60 s (음수 = 흔들림 뒤에 경보) |
| 전략 | S0 없음 / S1 밸브 / S2 펌프 / S3 밸브+펌프 / S4 밸브+공기압 |
| 예보 오차 | 실제 PGA × 0.5 / 1 / 2 |
| 실제 PGA | 0.2 / 0.4 / 0.6 g |
| 기록 · 시나리오 | 3개 × A·B |

- 기준(S0) = 0.2g에 최적화된 설정 고정 (ξ = 1, γ = 0.94)
- 평가 지표: **RMS 변위 저감률**(기록 3개 평균), **최대 스트로크 이용률**(기록 중 최대, 1 초과 = 물기둥 한계 도달)

### 실험 3 — 펌프 속도 민감도 (`w5_pump_sens.m`)
- 펌프 전 범위 시간 30 / 60 / 120 / 300 s × 리드타임 −3~120 s
- 시나리오 B, PGA 0.6 g, 펌프만(S2)

### 실험 4 — Simulink 재현 확인 (`w5_build_slx.m`, `w5_sim_run.m`, `w5_sim_compare.m`)
- 기본 블록만으로 `w5_tlcd_eew.slx` 자동 생성
  - Clock + Switch = 경보 시각 / Rate Limiter = 액추에이터 속도 / MATLAB Function = 건물+TLCD+Δ-DBG / Integrator ×2
- 스크립트와 같은 조건 12건 비교 (기록 3 × 리드타임 0·10 s × S0·S3)

## 6. 결과

### 결과 1 — 밸브를 미리 맞추면 물기둥 넘침을 막는다
| 조건 | S0 저감 / 스트로크 | 밸브 프리셋 저감 / 스트로크 |
|---|---|---|
| A · 0.6 g | 4.1% / **1.07** (넘침) | 4.2% / **0.90** |
| B · 0.4 g | 18.4% / **1.03** (넘침) | 16.3% / **0.83** |
| B · 0.6 g | 10.3% / **1.05** (넘침) | 11.0% / **0.93** |

- 넘침은 El Centro 기록에서 발생
- **리드타임과 무관** — 0 s여도, 경보가 3 s 늦어도 같은 효과 (밸브가 빨라서)
- 저감률 변화는 −2.1 ~ +0.7 %p로 작음 (B 0.4g의 감소는 한계를 지키는 대가)

### 결과 2 — 펌프는 미리 움직여도 효과가 없다 (실측 기록)
- 설정표에서 최적 γ가 지진 크기와 상관없이 **0.92~0.96으로 거의 일정** → 바꿀 값이 없음
- 모든 조건에서 펌프(S2) 이득 0 %p
- 반면 최적 ξ는 0.5~1 → 4 (0.8g 이상)로 크게 바뀜

### 결과 3 — 예보는 크게 잡는 게 안전하다
(밸브 프리셋, 시나리오 A, 실제 0.6 g, 최대 스트로크)

| 예측 | 결과 |
|---|---|
| 절반 (×0.5) | **1.09** — 넘침, 아무것도 안 한 것(1.07)보다 나쁨 |
| 정확 (×1) | 0.90 |
| 두 배 (×2) | **0.68** — 가장 안전 |

→ 운용 규칙: 예측 PGA를 일부러 크게 잡아 밸브를 설정

### 결과 4 — 펌프 속도가 필요 리드타임을 정한다 (합성파 조건에서만 확인)
| 펌프 전 범위 시간 | 30 s | 60 s | 120 s | 300 s |
|---|---|---|---|---|
| 필요 리드타임 | 2 s | 10 s | 30 s | 90 s |

- 필요 리드타임 ≈ 펌프 시간 × 0.3
- **실측 기록에서는 재튜닝 자체가 필요 없어서** 이 관계는 "재튜닝이 필요할 때"의 원리 확인용

### 결과 5 — Simulink가 스크립트 결과를 재현
- 저감률 차이 최대 **0.18 %p**, 스트로크 차이 최대 **0.011** (ode4 vs Newmark 적분 차이 수준)

### 참고 — 실측 기록의 현장 센서 리드타임 (부산 기준)
현장 센서는 P파 후 4.5 s에 경보 (논문 17)
- 포항: **7.2 s** / 경주: **2.4 s**

### 합성파 vs 실측 비교
| 항목 | 합성파 | 실측 |
|---|---|---|
| 최적 γ | B에서 PGA 따라 0.98 → 0.88~0.94 | 0.92~0.96 거의 일정 |
| 펌프 이득 | B에서 +1.6~3.1 %p | 0 |
| 밸브 포화 방지 | 1.07 → 0.72~0.78 | 1.03~1.07 → 0.83~0.93 |

→ **밸브 결론은 두 입력 모두 유지, 펌프 결론은 입력에 따라 달라짐**

## 7. 결론

1. 미리 움직일 **시간**보다 지진 크기를 미리 **아는 것(정보)**이 핵심
2. 빠른 밸브 + 크기 예보 → 리드타임 0 s로도 물기둥 넘침 방지
3. 1분 리드타임은 느린 펌프가 재튜닝해야 할 때만 의미 (지금 구조에선 불필요)
4. 예보는 과소평가하지 않는 것이 중요 → 보수적(크게) 설정

## 8. 실험 중 발견하고 고친 문제

| 문제 | 영향 | 조치 |
|---|---|---|
| 실측 기록에서 0.05g 임계값이 P파에 먼저 걸림 (포항 18.4 s vs S파 28 s) | 리드타임이 틀리게 계산됨 | 진앙거리 ÷ 3.5 km/s로 S파 도착 계산 |
| 기준 튜닝비를 0.98로 고정 (실측 최적은 0.94) | 펌프가 "예측 덕분"이 아니라 "기본값이 틀려서" 이득처럼 보임 | S0 기본값 = 설정표의 0.2g 최적값 |
| 스트로크를 기록 3개 **평균**으로 집계 | El Centro의 한계 초과가 가려짐 | 기록 중 **최대**로 변경 |
| 설정표 범위가 0.6g까지 | 2배 과대 예측(1.2g)이 0.6g로 잘림 | 범위 1.2g까지 확장 |
| Simulink 출력이 7×1×N 3차원 배열 | 저감률 100%라는 잘못된 값 | 2차원(N×7)으로 펴서 읽음 |
| 경주 기록 동서 성분 최대값이 장비 한계(2²³ counts) 초과 | 파형 잘림 | 1축은 남북 성분, 2축은 충주 관측소 기록 사용 |
| 2축 펌프 그림 제목이 "펌프가 느릴수록 리드타임이 필요하다"로 단정 | 실제 결과(순서대로 늘지 않음)와 맞지 않음 | 중립 제목으로 변경 |
| 2축 결과 정리 시 리드타임별 물기둥 값을 그래프 눈대중으로 적음 | "0 s 1.01"로 잘못 기재 (실제 1.001) | csv 데이터 값으로 수정 |

## 11. 추가 실험 — X·Y 2축 (4주차 기본안)

상세: `5주차_2축_실험결과.md` / 그림: `그림/2축/` / 실행: `AXES = 2; w5_main`

- X·Y 축마다 TLCD(μ 0.5%), 같은 지진의 두 성분 입력, 합성 변위 기준 평가
- 경주 기록은 부산 동서 성분이 포화돼 **충주(164 km)** 기록으로 대체

| 항목 | 1축 | 2축 |
|---|---|---|
| 밸브 프리셋 저감률 변화 | −2.1 ~ +0.7 %p | **+3.0 ~ +4.2 %p** |
| 밸브 프리셋 물기둥 | 1.03~1.07 → 0.83~0.93 | 1.06~1.09 → 0.98~1.02 |
| 강성 저하(B) 최적 γ | 거의 일정 | 강진일수록 0.86~0.92 |
| 재튜닝(펌프·공기압) 추가 이득 | 0 | B 0.6 g에서 +1.0 %p, 물기둥 0.98 → 0.94 |
| 필요 리드타임 | 밸브 0 s | 밸브 0 s, 재튜닝 추가 시 0~10 s |
| 예보 오차 | 과소 위험 · 과대 안전 | 같음 (×0.5 → 1.07, ×2 → 0.55~0.66) |

→ 2축에서도 **"정보가 핵심, 1분 리드타임은 필요 없음"** 결론 유지. 밸브 효과는 더 커짐.
