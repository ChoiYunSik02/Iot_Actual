## 1. TLCD 역학 (원문 2.1절, 식 1~9)

**액체 관성력**
```
F_m = −[ ρ·A_v·B·( (A_v/A_h)·D̈ + ẍ_n ) + 2ρ·H_v·A_v·D̈ ]                      (1)
```

**복원력**
```
F_R = 2ρ·A_v·g·D                                                              (2)
```

**감쇠력 — 관벽 마찰 F₁ + 오리피스 F₂**
```
F₁ = ½·ρ·A_h·δ₁·Ḋ²                                                            (3)
F₂ = ½·ρ·A_h·δ₂·λ²·Ḋ²                                                         (4)
δ₁ = (1 − λ)² + 0.5·|1 − λ|                                                   (5)
δ₂ = [ (1 − κ) + 0.707·(1 − κ)^0.375 ]² · (1/κ)²                              (6)
F  = F₁ + F₂ = ½·ρ·A_h·δ·|Ḋ|·Ḋ,     δ = δ₁ + λ²·δ₂                            (7)
```

**TLCD 운동방정식**
```
( 2ρA_vH_v + ρ·(A_v²/A_h)·B )·D̈ + ½·ρ·(A_v²/A_h)·δ·|Ḋ|·Ḋ + 2ρA_v·g·D = −ρ·A_v·B·ẍ_n     (8)
```

**진동수**
```
ω_d = √( 2ρA_v·g / (2ρA_vH_v + ρ·(A_v²/A_h)·B) ) = √( 2g / (2H_v + λB) ) = √( 2g / L )   (9)
L = 2H_v + λB
```

- ✔ 검증: ω_d = 2π × 0.3542 Hz이면 L = 2g/ω_d² ≈ 3.961 m, 0.3204 Hz이면 L ≈ 4.841 m. 원문 [3.957, 4.834] m와 맞습니다(반올림 차이).
- 식 (7)과 식 (8)의 감쇠항 계수가 다릅니다(ρA_h vs ρA_v²/A_h). 식 (7)은 수평부 기준, 식 (8)은 수직부 변위 D로 환산한 형태로 보입니다. **재현에서는 식 (8) · (24)의 형태(ρA_v²/A_h)를 씁니다.**

## 2. 제어 알고리즘 (원문 2.3절, 식 10~13)

**① 진동수 범위 제한** (Y도 같은 형태)
```
ω_dx(t) = ω_dx,min    if ω(t) < ω_dx,min
        = ω(t)        if ω_dx,min ≤ ω(t) ≤ ω_dx,max                            (10)
        = ω_dx,max    if ω(t) > ω_dx,max
```
- ω(t): 최상층 변위계 신호를 웨이블릿 변환해 얻은 순간 진동수
- 범위: [0.3204, 0.3542] Hz (1차 진동수 ±5%)

**② 양방향 가중 진동수**
```
ω_d(t) = ( |D_y(t)|·ω_dy(t) + |D_x(t)|·ω_dx(t) ) / ( |D_y(t)| + |D_x(t)| )     (11)
```
- D_x(t), D_y(t): RS-TLCD가 놓인 층의 실시간 X · Y 변위
- ω_d(t) → 식 (9)로 목표 수위 계산 → 펌프 · 전자밸브 구동. 갱신 간격 Δt_f = 2.6 s

**③ 가변 감쇠** (갱신 간격 1 s)
```
[v_dx − v_nx]·a_nx ≤ 0  and  [v_dy − v_ny]·a_ny ≤ 0   ⇒  c_d = c_min
[v_dx − v_nx]·a_nx > 0  and  [v_dy − v_ny]·a_ny > 0   ⇒  c_d = c_max          (12)
[v_dx − v_nx]·a_nx ≤ 0  and  [v_dy − v_ny]·a_ny > 0   ⇒  c_d = c_opt
[v_dx − v_nx]·a_nx > 0  and  [v_dy − v_ny]·a_ny ≤ 0   ⇒  c_d = c_opt
```
- v_dx, v_dy: 수평부 액체 유속의 X · Y 투영 속도 (유량계)
- v_nx, v_ny, a_nx, a_ny: n층(설치층)의 속도 · 가속도
- c_min / c_max / c_opt ↔ 개구율 κ = 0.8 / 0.1 / 0.4 (원문은 κ 범위만 제시, 매칭은 우리 해석 ⚠️)

**④ 회전각** (갱신 간격 2.6 s, 회전 속도 30°/s)
```
θ(t) = arctan( D_y,max(t − t_R : t) / D_x,max(t − t_R : t) )                    (13)
```
- 지난 t_R 동안의 X · Y 최대 변위로 방향 결정. ⚠️ t_R 값은 원문에 없음 → 각도 갱신 간격과 같은 2.6 s로 가정

## 3. 전체 운동방정식 (원문 3.1절, 식 14~25) ★

```
M·Ü + C·U̇ + K·U = −M·E·Ü_g                                                    (14)
```

**질량 행렬**
```
M   = diag[ M_x, M_y, M_θ ]                                                   (15)
M_x = diag[ m_1, m_2, …, m_n, m_dx ]                                          (16)
M_y = diag[ m_1, m_2, …, m_n, m_dy ]                                          (17)
M_θ = diag[ J_1, J_2, …, J_n ]                                                (18)
```
- m_dx = m_d·cos θ(t), m_dy = m_d·sin θ(t)

**강성 행렬**
```
      ⎡ K_x    0     K_xθ ⎤
K  =  ⎢ 0      K_y   K_yθ ⎥                                                    (19)
      ⎣ K_θx   K_θy  K_θ  ⎦
```

```
       ⎡ k_x1+k_x2   −k_x2                                                       ⎤
       ⎢ −k_x2       k_x2+k_x3   −k_x3                                           ⎥
       ⎢             −k_x3        ⋱          ⋱                                    ⎥
K_x =  ⎢                          ⋱    k_x(n−1)+k_xn       −k_xn                  ⎥   (20)
       ⎢                               −k_xn          k_xn + k_dx(t)    −k_dx(t)  ⎥
       ⎣                                              −k_dx(t)           k_dx(t)  ⎦

k_dx(t) = 2·m_dx·g / (H_vL + H_vR + λB) · cos θ(t)
```
- K_x는 (n+1) × (n+1): 1~n층 + TLCD 자유도
- K_y, K_θ도 같은 방식 (K_y는 m_dy, sin θ 사용 / K_θ는 TLCD 자유도 없이 n × n)

**병진-비틀림 연성**
```
K_xθ = K_θxᵀ = K_x · e_y                                                       (21)
K_yθ = K_θyᵀ = K_y · e_x                                                       (22)
```

**변위 벡터** (크기 3n + 2 = 92)
```
U = [ u_x1, …, u_xn, u_dx,  u_y1, …, u_yn, u_dy,  u_θ1, …, u_θn ]ᵀ             (23)
```

**TLCD 실시간 감쇠 계수**
```
c_dx(t) = ½·ρ·(A_v²/A_h)·δ·|u̇_dx|                                              (24)
```
- c_dy(t)도 같은 형태. C는 구조물 Rayleigh 감쇠(모드 감쇠 2%)에 c_dx, c_dy를 더해 만듦

**지진 입력**
```
Ü_g = [ ü_xg, ü_yg ]ᵀ                                                          (25)
```

## 4. ⚠️ 원문만으로는 정해지지 않는 것 — 재현 때 우리가 정해야 함

| # | 문제 | 원문 상태 | 우리 처리 (제안) |
|---|---|---|---|
| 1 | **식 (21) · (22) 크기가 안 맞음** | K_x는 (n+1)×(n+1)인데 K_θ는 n×n → K_xθ = K_x·e_y는 (n+1)×(n+1)이 되어 (n+1)×n 자리에 안 들어감 | 구조물 부분(TLCD 행 · 열 제외한 n×n 층 강성)에 e_y를 곱하고, TLCD 행은 0 |
| 2 | **cos θ가 두 번 들어감** | m_dx = m_d·cos θ인데 k_dx에도 m_dx와 cos θ가 함께 있음 → k_dx ∝ cos²θ, 질량 ∝ cos θ라 X 방향 등가 진동수가 √cos θ배로 어긋남 | 두 가지 다 구현해 원문 표 4~7과 맞는 쪽 선택. 기본값은 k_dx = m_dx·2g/L (cos 한 번) |
| 3 | **E 행렬 정의 없음** | "conversion matrix"라고만 함 | (3n+2)×2: X 자유도(1~n층 + TLCD)는 ü_xg 열에 1, Y 자유도는 ü_yg 열에 1, 비틀림은 0 |
| 4 | **TLCD 감쇠가 어느 속도에 걸리나** | 식 (24)는 u̇_dx만 씀 | 질량-스프링(TMD) 형태라 **상대속도 (u̇_dx − u̇_xn)** 로 해석. 감쇠 행렬 위치도 K_x의 k_dx와 같은 패턴 |
| 5 | **A_v, A_h, B 값 없음** | λ, L 범위, m_d만 있음 | m_d = ρ·A_v·L 계열로 역산 필요 — 등가 질량-스프링 모델에서는 c_dx 계산(식 24)에만 A_v²/A_h가 필요. B · A_v를 가정하고 민감도 확인 |
| 6 | **Rayleigh 감쇠 기준 모드** | "모드 감쇠비 2%"만 | 1차 · 2차 모드 2%로 구성 (일반 관례) |
| 7 | **비틀림 강성 기준점** | 강성 중심 = 기하 중심, 편심은 질량 중심 기준 | 원문 식 그대로 (K_θ 대각에 e² 항 추가 안 함) — 표 1 고유진동수로 검증 |
| 8 | **TLCD 평면 위치** | 그림 5(c)에 그려져 있지만 좌표 없음. 식에서도 TLCD는 θ 자유도와 직접 연결 안 됨 | 원문 식 그대로 (TLCD는 X · Y 병진에만 연결) |
| 9 | **t_R, c_min · c_max · c_opt 수치** | 없음 | t_R = 2.6 s, c ↔ κ = 0.8 / 0.1 / 0.4 |
| 10 | **적분 방법 · 시간 간격** | MATLAB이라고만 함 | Newmark-β 평균가속도, Δt = 0.005 s (기록 간격 맞춤) |
| 11 | **수동 TLCD 경우** | X · Y 각각 463,178 kg, θ 고정 | 별도 장치 2개: X용은 θ = 0°, Y용은 θ = 90° (m_dx · m_dy에 cos · sin 없이) |

**검증 순서**
1. TLCD 없이 고유진동수 → 표 1 (0.3373, 1.0112, 1.6831 … Hz)과 맞는지. 1차 모드 질량 참여율 83.76%
2. 수동 TLCD → 표 4~6의 Passive 열
3. S-TLCD · RS-TLCD → 표 7 평균
