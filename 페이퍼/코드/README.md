# 타깃 논문 재현 코드 — Fu et al. (2025) 30층 편심 건물 + RS-TLCD

식과 가정은 `페이퍼/01_타깃논문_정리.md` 기준입니다(식 번호 = 원문, "처리 #n" = 그 문서 4절).

| 파일 | 내용 |
|---|---|
| `rstlcd.py` | 건물 행렬(식 15~23), 장치(식 5~9 · 24), 제어 알고리즘(식 10~13), Newmark 적분, 지표 |
| `records.py` | 입력 지진: PEER 15쌍(`페이퍼/입력/PEER/`) · 보유 3쌍, 35 cm/s² 정규화 |
| `check_model.py` | 고유진동수 점검 + 무제어 / 수동 / S-TLCD / RS-TLCD 저감률 (원문 표 7 형식) |

필요: Python 3, numpy (scipy · numba 불필요). MATLAB 툴박스 함수 안 씀.

```
cd 페이퍼/코드

python check_model.py --cos2       # 식 (20) 그대로 cosθ 두 번
```

## 현재 상태 (2026-10-14)

**1) 건물 모델 — 원문과 일치 ✔**
- X 방향 고유진동수 10개가 원문 표 1과 **소수 넷째 자리까지 같음** (0.3373, 1.0112, 1.6831 … Hz)
- 1차 모드 질량 참여율: 연성 모델 1~3차 합 **83.76%** = 원문 값
  - 단, 편심으로 연성되면 0.3373 Hz 주변이 **0.2714 / 0.3373 / 0.3953 Hz** 세 모드로 갈라짐. 원문 표 1과 83.76%는 연성을 뺀 X 방향 값으로 보임

**2) TLCD 감쇠 — 식 (24) 그대로면 너무 작음 ⚠️**

- ⚠️ **고정값 기준선** (`const_baseline.py`, `results/ai_const_baseline.log`): RS-TLCD를 지진과 상관없이 **(0.3204 Hz, 45°)** 로 미리 맞춰 두면 **15.76%** — AI preset(15.77%)과 같음. 11쌍 평균이 가장 좋은 고정 칸 (0.3204 Hz, 30°)은 15.89%. 라벨에서도 (0.3204 Hz, 45°)가 가장 흔함 (243/2000).
  - 즉 원문 RS 대비 +2.4%p의 대부분은 **"웨이블릿 추종 대신 미리 낮춰 고정"** 에서 나옴. AI가 지진마다 다르게 맞춰서 얻는 몫은 아직 거의 없음 (Oracle − 최선 고정 = 0.6%p 여유).
