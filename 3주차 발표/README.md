## 이번 발표의 논지

> 3층 모델에서 TLCD가 안 되는 이유는 **주파수가 아니라 규모**였다.

1. 모델 검증 1~3단계 통과 (오차 0.000%) → **구현은 정확하다**
2. 4단계에서 3층 저감률 0.5% → **조건의 문제로 좁혀짐**
3. 논문 3편에서 건물 제원 추출 → 같은 기준으로 계산
4. **성능**은 질량비로 결정(절대 질량 무관), **실현 가능성**은 진동수 + 절대 질량으로 결정
5. 판정 지표 **종횡비 h/D** 도입 → 실현 가능성 지도
6. 논문들도 같은 난점 때문에 변형 장치(sealed, compliant, sliding)를 쓰고 있었다

## 발표 시 주의

- **13번 슬라이드 동영상**은 PPTX에 포함돼 있습니다. 발표장 PowerPoint에서 재생되는지 미리 확인하세요. 안 되면 12번 정지화면으로 충분히 설명됩니다.
- 건물 변위는 모델마다 크기가 달라 **보기 좋게 정규화**했습니다. U자관 종횡비만 실제 비율입니다.
- 현재 지진파는 **합성파**입니다. 종횡비 계산은 기하학이라 영향받지 않지만, 저감률 수치는 4주차에 실측 기록으로 교체 후 재산출해야 합니다.
- JOBE 2025의 길이비는 논문에 면적비로 표기돼 있어 **0.80으로 가정**했습니다(7번 슬라이드 각주).
