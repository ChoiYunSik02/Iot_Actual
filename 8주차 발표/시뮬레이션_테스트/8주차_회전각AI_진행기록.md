## 2. 교수님 피드백 기준으로 AI·파이프라인 재검토
연동 폴더의 기존 발표대본·계획서에서 확인한 피드백:
| 주차 | 피드백 |
|---|---|
| 2주차 | 무게추를 물로 채우는 방식(TLCD) |
| 5주차 | 지진 몇 초 전에 미리 움직이는 예측 제어 |
| 6주차 | PGA가 아니라 **유입 진동을 예측해 값을 미리 조정**, 특정 논문의 건물 값을 그대로, 보유 지진 전부 입력 |
| 10/27 정리 | IoT 액추에이터 과목이므로 결론은 "액추에이터를 어떻게 구성해 감쇠를 개선했나", AI는 필수 아님 |

기존 AI(지반가속도 파형 예측 + 세 장치 후보를 고르는 점수망)의 문제:
1. 예측 대상이 피드백("진동 예측 → 미리 조정")과 어긋남.
2. 이전 진단(ai_improvement_v4)에서 미래 입력을 완벽히 알아도 R 대비 +0.5%p, 더 좋은 예측의 여지 +0.25%p.
3. 새 재현 모델에서 AI가 무작위 후보 선택(RAND3)과 구별되지 않음 → 이득이 학습이 아니라 "시뮬레이터로 후보를 평가하는 구조"에서 나옴.
4. 구성 요소가 많아 무엇이 효과를 냈는지 분리 불가.

새 파이프라인 원칙: **한 번에 한 장치, 상한부터 측정** → 단순 예측 기준 → AI → 같은 조건 비교 → MATLAB/Simulink 확인.

## 3. 1단계 상한 시험: 어느 액추에이터를 미리 움직여야 하나
조건: 재현 모델 D0·A(rs_ref), 15기록, 한 장치만 "미래를 아는" 조건으로 바꾸고 나머지는 원문 규칙. 지표는 무제어 대비 6지표(X·Y·θ의 최대·RMS) 평균 저감률. R = 15.81%.
| 바꾼 장치 | 평균 | R 대비 |
|---|---|---|
| 펌프: 원문 규칙이 2.6초 뒤 낼 진동수를 지금 적용 | 15.95% | +0.14%p |
| 펌프: 다음 구간 응답으로 식별 | 15.89% | +0.08%p |
| 펌프: 기록별 최선 고정값(사후) | 16.24% | +0.43%p |
| **회전판: 다음 2.6초의 주 진동 방향을 지금 적용** | **18.87%** | **+3.06%p** |
| 회전판 45° 고정 | 16.73% | +0.92%p |
| 회전 속도 제한 없음 | 16.29% | +0.48%p |
| 밸브: 1초 대신 매 스텝 판단 | 16.60% | +0.79%p |
| 밸브: 0.4 고정(밸브 제어 없음) | 15.03% | −0.78%p |
| 세 장치 모두 선행 + 지연 없음 | 19.78% | +3.97%p |

결론: 펌프는 조절 범위가 0.320~0.354 Hz(±5%)로 좁아 진동수를 완벽히 예측해도 이득이 작다. 원문 회전 규칙은 지난 2.6초의 최대 변위 방향을 따라가 한 박자 늦으므로, **AI의 예측 대상을 "다음 2.6초의 주 진동 방향(회전판 목표각)"으로 변경**. 교수님 피드백의 취지(유입 진동 예측 → 미리 조정)를 효과가 있는 액추에이터에 적용한 것.

## 4. AI 설계 (학습 전 고정, angleai/PREREG.md)
- 입력: 판단 시점까지의 옥상 X·Y 변위, X·Y 지반가속도에서 만든 특징 13개(최근 1.3/2.6/5.2초·전체 이력의 최대 변위 방향, 지반 방향, RMS 방향, 응답 증감, 현재 각도, 경과 시간 등).
- 모델: MLP 은닉층 (32, 32), tanh, 입력 표준화, L2 1e-3, 시드 0. 추론 0.012 ms.
- 출력: 다음 2.6초 구간의 최대 변위 방향 arctan2(max|Y|, max|X|), 0~90°.
- 제어: 회전판 목표각만 AI가 정함. 펌프(식 10·11)·밸브(식 12, 해석 A)·회전 속도 30°/s·판단 주기 2.6초/1초는 원문 그대로.
- 학습 자료: 논문 15기록과 겹치지 않는 8개 지진(포항 2017, 경주 2016, El Centro 1940, Chuetsu-oki 2007, Düzce 1999, Manjil 1990, San Fernando 1971, San Simeon 2003). 입력 쌍을 0·30·60·90·120·150° 회전해 48회 실행.
- 학습 방법: R로 폐루프 실행해 자료 수집 → 학습 → AI로 다시 실행해 자료 추가(DAgger 1회) → 재학습 → 최종 고정.
- 시험: 논문 15기록(학습 미사용). 비교군: R, 비학습 방향 규칙(1.3초/5.2초/전체 이력), AI, 상한(LEAD).
- 성공 기준(사전): AI − R > 0, AI가 비학습 최선보다 높을 것, 비틀림 악화 기록 수 보고.
