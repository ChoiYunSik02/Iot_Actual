# 8주차 v2 설계: 펌프·회전판·밸브 공동 선택 (J)

근거 계획: `8주차: 상태·지연 기반 AI의 펌프·회전판·밸브 협조 제어 실행 계획` (v2). 이 문서는 학습·폐루프 실행 전에 고정한 구현 규칙이다.
기존 실험(F8, C1 주 구조)의 사전 등록을 소급 수정하지 않는다. 새 탐색적 실행 버전이며, 모든 실제 기록은 개발 평가다.

## 1. 시간축과 결정 (정수 스텝, dt = 0.01 s)
| 항목 | 규칙 |
|---|---|
| 느린 결정 | 펌프·각도 격자 gS (260의 배수)에 적용. 결정 시각 gS − d_cmd |
| 빠른 결정 | 밸브 격자 gV (100의 배수, 260의 배수가 아닐 때)에 적용, κ만. 결정 시각 gV − d_cmd_V |
| 격자가 겹침 (1300의 배수) | 느린 결정 한 번. κ도 그 결정에서 gS에 적용 |
| 원래 시각 R 경로 | 모든 격자 g의 g − d_cmd_R에 원래 R 법칙(진동수·각도·밸브)을 그 시각 관측으로 실행 |
| 적용 | 펌프·각도 = 받아들여진 느린 제안, 아니면 R. 밸브 = (1) 제때 준비된 빠른 결정(R 선택 포함) → (2) 느린 결정의 κ 계획 → (3) R |
| 조건 | d_cmd_R ≤ d_cmd ≤ 150, d_cmd_R ≤ d_cmd_V < 100 (어기면 실행 거부) |

- 느린 결정의 κ는 gS 이후 첫 밸브 격자 gk = ⌈gS/100⌉·100에 적용할 계획값이다. 예측에서는 gk 전까지 현재 밸브를 유지하고, gk부터 그 κ를 유지한다.
- 이미 보낸 지령은 바꾸지 않는다. 아직 보내지 않은 이전 격자 제안은 예측에만 가등록한다(보내지 않음).
- 모든 제안을 거부하면 R 방식과 같은 시각·관측·지령이 된다(시험 T12a). 제안이 한 번 적용된 뒤 R로 돌아가도 원래 R 응답으로 돌아간다는 보장은 없다.

## 2. 후보 (`enumerate_joint_candidates`)
- 느린 결정: 유지(현재 목표 f·θ·κ) → R tuple(현재 관측의 R 법칙 f·θ, 밸브 법칙) → f {현재 목표 −0.005, 0, +0.005 Hz}(범위 [0.3204, 0.3542]로 제한) × θ {0, 22.5, 45, 67.5, 90}° × κ {0.1, 0.4, 0.8}, ID 3~47
  - 같은 tuple은 앞의 것만 남긴다. R은 법칙 기반이므로 값이 같아도 따로 둔다. 실제 후보 수는 결정마다 기록한다(범위 끝에서 31, 그 밖에서 46~47).
- 빠른 결정: 유지 κ(ID 101) → R(법칙, 102) → κ 0.1/0.4/0.8 (103~105), 중복 제거 후 최대 5
- C1J(밸브 절제): 느린 후보의 κ를 모두 법칙으로 두고(유지 포함), 빠른 결정을 하지 않는다. 펌프·각도 후보·비용·시간축은 J와 같다.
- 동점 순서: 유지 → R → 고정 ID. 비용 비교는 정확한 부동소수 비교(같으면 앞의 것)로 한다. 제한식 여유는 상대 1e-12.

## 3. 비용과 제한 (`filter_and_apply_joint_action`)
- 비용: 기존 C1 식 그대로. J = mean(((ux/sx)² + (uy/sy)² + (θ/sθ)²)/3) + 0.05·(Δf/범위 + Δθ/범위)/2. 스케일은 `config/scales.json`(학습 기록 R에서 정함). 밸브 전환에 별도 weight를 두지 않고, 전환 횟수와 κ 이동량을 보고한다.
- 그림자 R 제한(기존 `design_shadowR.md` 4절과 같은 식, 결정 종류별 R 후보만 다름):
  - Q̂_c = Qa(s) + Σθ̂_c², M̂_c = max(Ma(s), max|θ̂_c|)  (스텝 s+1 … 예측 끝)
  - Q̂_R, M̂_R = 그림자 R 상태(관측 시각 s)에서 같은 예측 입력으로 R 법칙을 유지한 값
  - 만족: Q̂_c ≤ Q̂_R(1+tol) 그리고 M̂_c ≤ M̂_R(1+tol). 두 여유를 서로 상쇄하지 않는다. R 후보는 항상 허용.
  - R 외 만족 후보 없음 → R (`no_feasible`, 제한 만족으로 세지 않음). 예측 없음·지평 부족·NaN·늦음 → R, 사유 기록.
- 제한은 예측에 의존하며 실제 전체 기록의 비틀림 무악화를 보장하지 않는다.

## 4. 점수망 입력 (`build_state_features`, 98열, 이상적 상태정보 조건)
| 열 | 내용 (단위) |
|---|---|
| 1-6 | 최상층 X·Y 변위(m), 비틀림(rad), 각 속도(m/s, rad/s) — 관측 시각 s의 플랜트 상태 사본 |
| 7-10 | 장치 일반좌표 IDX·IDY와 속도 (기준 엔진 좌표, 단일 액주 좌표로 해석하지 않음) |
| 11-19 | 장치 실제 f·θ·κ, 목표 f·θ·κ, 목표 − 실제 |
| 20-25 | 관측 나이, 예측 나이, 적용 격자까지 시간, 대기 지령 수, 펌프 램프 남은 시간, 회전 남은 시간 (s) |
| 26-29 | 대기 지령의 마지막 f·θ·κ, 가장 이른 대기 지령까지 시간 |
| 30-37 | 실제 X·Y·비틀림 최대와 제곱합(관측 s까지), 그림자 R의 비틀림 제곱합·최대(같은 시각) |
| 38-85 | 예측 4 s를 0.5 s 8구간으로 나눈 X·Y별 평균·RMS·최대|·| (zero·persistence·AI 같은 변환) |
| 86 | 예측 유효 |
| 87-98 | 후보 f·θ·κ, 현재 목표 대비 차이, 마스크(f·θ·κ 숫자), isR, isHold, 빠른 결정 |

- 사건명·기록명·전체 기록 통계·실제 미래는 넣지 않는다. 표준화는 teacher train 통계(분산 0인 열은 1로 나눔).
- 대기열: CommandQueue에 들어간 적용 전 지령 전체(용량 제한 없음, 장치별 마지막 값이 적용).

## 5. Teacher와 점수망 (`generate_joint_teacher`, `python/train_joint_scorer.py`)
- 기록: 합성 1,000 원천(생성 시드 84000~84999, 분할 시드 8400, 800/200)에서 시드 8401로 train 80, val 20. 실제 기록 미사용.
- 진동 구간: 같은 기록의 R 응답에서 직전 2.6 s 정규화 에너지가 최대의 25 % 이상인 격자. 예측이 준비된 뒤(트리거 + 1.5 s 이후), 평가 지평 2 s가 남는 격자만.
- 상태: 기록당 최대 8 (느린 4 + 빠른 4, 시드 고정 무작위). 두 rollout에 번갈아 배정 — R rollout(항상 R)과 탐색 rollout(후보 무작위 적용, Park–Miller 시드 9100 + 생성 시드).
- 라벨: 모든 후보를 실제 미래 지반입력으로 모의 → J_true, 실제 미래 그림자 R 제한 여유. 비인과 teacher이며 입력 특징은 그 시각에 준비된 AI 예측으로 만든다.
- 목표 y = J_true/J_true(R) − 1 (상태마다 R로 정규화한 비용). 망 98 → 128 → 64 → 1, ReLU, Huber, Adam 1e-3, batch 128, 최대 50 epoch, val 손실 patience 5, seed 8401, 최저 val 손실 checkpoint.
- 처리량: 합성 2기록(train·val 각 1)으로 먼저 재고, 100 기록 추정이 6 h를 넘으면 성능 평가 전에 상태 8 → 4로 한 번 줄인다(`results/joint_teacher_plan.json`).
- 지표(느린 결정): top 3 적중, 검사 집합(top 3 + 유지 + R) 최선 포함률, regret(J_R 대비), fallback(top 3 모두 불만족), 무작위 3개 기준선.
- 자료 보강(정책 rollout 1회)은 시간이 남을 때만. 생략하면 분포 차이 한계로 명시한다.
- MATLAB 추론(`rank_joint_candidates`)은 Python 출력과 ≤ 1e-9로 대조한다(JS 단계).

## 6. 비교 (`run_joint_comparison`)
| 방식 | 예측 | 후보 평가 |
|---|---|---|
| R | — | 원래 R |
| J-zero / J-persistence | 단순 예측 | 전체 후보 물리 평가 |
| J-AIF | 파형 AI | 전체 후보 물리 평가 |
| **J-AI (주 실험)** | 파형 AI | 점수망 top 3 + 유지 + R만 물리 평가 (느린), 빠른 결정은 전체 |
| C1J-AI | 파형 AI | 전체 후보, 밸브는 R 법칙 |
| J-PREVIEW | 실제 미래 | 전체 후보 (엄밀한 상한 아님) |

- 주 비교는 공통 고정 시간축이다. 모든 방식에 같은 d_cmd·d_cmd_V(J-AI 지속 부하 p99, 난수 가중치의 같은 구조 점수망으로 학습 전에 측정)를 준다. 이상화 알고리즘 비교이며 전체 후보 방식은 실시간 불가일 수 있다. 실행 가능성은 방식별 실측 계산시간 p99(느린 ≤ 1.5 s, 빠른 < 1 s)로 따로 판정하고, J-AI는 실측 지연으로 한 번 더 실행한다.
- 차이 해석: J-AIF − 최선 단순 = 파형 예측 효과, J-AI − J-AIF = 점수망 후보 축소의 손실·이득, J-AIF − C1J-AI = 밸브 공동 선택 기여.
- 보고: 6지표 사건 평균, 사건별, 비틀림 최대·RMS 여유와 위반 사건·기록, 구동량(회전·펌프·밸브 전환·κ 이동), 느린 결정의 유지/R/tuple 비율, 점수망 tuple 실제 적용 수, 빠른 결정의 후보/R 비율, 장치별 R과 다른 지령 비율, 계산시간, late·no_feasible.
- 사건: 개발 3사건(El Centro·고베·포항) 먼저, 계산시간이 허락하면 같은 설정으로 기존 11개 기록(JCX).
