## 2. 비틀림 위반 재집계
- 주 집계 = **위반 기록이 하나라도 있는 사건**. 기록 위반 = 같은 조건 R보다 θ 최대 또는 θ RMS 저감률이 낮음(허용 0 %p, 상대 1e-12). 사건 저감률 평균 기준 집계는 보조 열로 분리했다(`aux_torsion_violation_events_by_event_mean`).
- J-AI 고정 시간축: 8쌍에서 위반 기록 Mexicali(θ RMS −2.82)·고베(θ RMS −1.64) → **Imperial Valley·고베 2사건**(보조 기준 1). 11기록에서는 포항·경주가 더해져 **4사건**(보조 3). 실측 2차(JCA) 11기록은 Mexicali·고베·포항 → **3사건**(보조 2). 개발 3사건은 고베·포항 2사건.
- v2 보고서의 "위반 사건 3"(11기록)은 보조 기준이다. v2 문서는 바꾸지 않았고 v3에서 주 집계로 다시 센 값이 4다.

## 3. 원문 R 재현에서 알게 된 것
- 같은 8쌍에서 원문 RS-TLCD의 6지표 평균 저감률은 **20.29 %**(표 4-6에서 계산), 현재 R은 **16.22 %**(운영 시간축) / 16.12 %(지연 0, MATLAB, dt 0.01) / 15.98 %(지연 0, dt 0.005)다. **이 격차(약 4.1 %p)는 시험한 지연·dt 변경만으로 설명되지 않았다.** 최대값 지표(X 최대 −4.5, Y 최대 −5.6, θ 최대 −5.7 %p)가 RMS 지표(−1.1 ~ −4.4 %p)보다 격차가 크다.
- 다른 원인 후보(×30 감쇠 보정, 단면적·B 미확정, 웨이블릿 식별 방식, 회전각 범위, 회전 분해식, 진폭 정규화, 기록 길이)는 시험하지 않았고 어느 것도 결과를 보고 골라 맞추지 않았다.
- 무제어 RMS가 원문보다 5–14 % 낮은 것은 끝에 붙인 10 s 0 구간 때문으로 보인다. 빼면 7쌍에서 0.94–1.02다(민감도 열). 이후 결과의 RMS 정의는 바꾸지 않았다. Chi-Chi는 0.65로 설명하지 못했다.
- 원문 표 4-6에서 계산한 RS-TLCD 평균이 표 7과 최대 0.21 %p 다르다(수동·S-TLCD는 0.02 이내). 원문 내부 불일치로 보고 둘 다 남겼다.
- **"원문 동일 조건 완전 재현"이라고 말하지 않는다.** 고유진동수 일치(이전 B 관문)는 구현 대조일 뿐 원문 제어 성능 재현이 아니다.

## 5. 시간축과 실측 지연
- 주 비교는 고정 시간축(느린 0.27 s, 빠른 0.22 s)이다. 전체 후보 방식은 결정당 1.8–2.1 s라 이 노트북에서 실시간 불가이며, 비학습 비교는 이상화한 알고리즘 비교다.
- 실측 지연은 두 번 실행했다. **같은 개발 3사건**(고베·El Centro·포항)으로 맞춘 비교: 1차(JC) +0.11, 2차(JCA) +1.43 %p(고정 시간축도 +1.43). 두 실행 모두 위반 기록이 있는 사건은 고베·포항이다. 2차의 8쌍 +3.42, 7사건 +3.64 %p는 **별도의 확대 평가**다.
- El Centro(+0.71 대 +4.65): 로그에서 확인한 것(`el_centro_late_decisions_check.txt`) — 1차에서 선택 계산이 예산 0.27 s를 넘긴 느린 결정 2개(결정 4.93·7.53 s, 계산 0.271·0.278 s)가 마감 초과로 R 지령으로 대체되었고, 2차·고정 시간축은 마감 초과 없이 지령 83개가 모두 같으며, 1차는 5.20 s 적용 격자부터 49개 격자에서 다르다. **같은 늦은 결정만 재현하는 지연 패턴 재생은 하지 않았으므로 성능 차이의 단일 원인으로 확정하지 않는다.**
- 실측 지연은 실행 때 컴퓨터 속도·부하에 따라 바뀌므로 한 실행을 대표값으로 쓰지 않는다.
