# 8주차 제출 CHANGELOG (기존 관문과 이번 탐색 실험의 관계)

- 기존 D·D2·RP 결과와 사전 기준(G1~G4, 비틀림 허용 0 %p)은 그대로 보존한다(`report/`, `config/CHANGELOG.md`).
- 이번 실험은 G2·G3 미충족 이후 실시한 **범위 제한 탐색 실험**이다. 기존 관문 통과로 표시하지 않는다.
- 관문 G1(A·B·SL·C)은 이번 코드로 노트북 MATLAB에서 다시 통과했다. 시험 T10(원래 R 재현)과 T11(그림자 R 일치·인과성)을 추가했다.

## 변경 (모두 폐루프 결과를 보기 전)
1. 원래 시각 R 경로(`default_path='ontime'`): 모든 제안을 거부하면 원래 R과 비트 단위로 같다(T10).
2. 그림자 R 누적 비틀림 제한(`constraint='shadow'`)과 절대 각도 후보(`angle_mode='absolute'`). 수식은 `report/design_shadowR.md` 4·5절.
3. AI 학습: 합성 1,000 원천(800/200), 실제 기록 학습 제외, 최대 100 epoch·인내 10, seed 8401(필수)·8402·8403
4. 비교 시간축: 지속 부하 p99 예산의 고정 시간축 + 실측 지연 1회. 계산량 규칙(예산 > 1.5 s면 진동수 후보 축소)은 이번에 적용되지 않았다.

## 실행 중 오류와 조치 (결과 수치에 영향 없음)
- F8 1차: 예산 측정 실행의 선택 예산 0 → ontime 경로에서 제안이 쓰이지 않아 측정 기록이 없어 중단됐다. 측정용 예산을 1스텝으로 고치고, `d_cmd < d_cmd_R`이면 오류를 내도록 했다.
- F8 2차: 폐루프는 모두 끝났으나 예측 내보내기 함수(`trig100`) 누락으로 중단됐다. 저장된 결과를 재사용(F8R)해 내보내기만 다시 했고, 폐루프는 다시 돌리지 않았다.
- 절전으로 중단된 실행 1회는 처음부터 다시 실행했다.
