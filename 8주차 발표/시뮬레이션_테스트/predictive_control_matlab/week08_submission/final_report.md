## 2. 설정 (사전 지정 `report/prereg_week8_final.md`)
**제어 구조**
- 주 구조: C1 + 원래 시각 R 경로 + 그림자 R 누적 비틀림 제한 + 절대 각도 {현재, 0, 22.5, 45, 67.5, 90}° × 진동수 3 + R
  - 후보는 결정마다 11~19개였다.
- 참고 구조: 현행 C1(±15°, 예측 구간 R 후보 비교) + 원래 시각 R 경로

**시간축**
- 고정 시간축이다. 선택 예산은 지속 부하 p99로 측정했다(주 구조 0.85 s → d_cmd 85, 현행 C1 0.45 s → d_cmd 45).
- 센서·통신 0, 예측 준비 1스텝, R 1스텝
- 계산량 규칙(예산 > 1.5 s면 진동수 후보 축소)은 적용되지 않았다.

**AI**
- 구조: LSTM(64) → FC128 → FC800, 입력 5 s 창, 4 s 앞 X·Y 지반가속도
- 학습 자료: 합성 1,000 원천(800/200), 창 32,000/8,000
- 실제 기록은 학습과 체크포인트 선택에 쓰지 않았다.
- 폐루프에서는 같은 가중치를 MATLAB으로 재구현해 썼다(Python과의 출력 차 4.7×10⁻⁷).

## 5. 해석
1. 구조 개선(원래 R 경로 + 그림자 R + 절대 각도)으로, 실제 미래 입력을 준 같은 제어기의 참고 성능이 +0.25에서 +4.45 %p로 커졌다(현행 C1 → 주 구조). 제어 구조에 여지가 생겼다는 뜻이다.
2. 그 여지를 AI가 쓰지 못했다(개발 3사건 +0.5~1.2 %p, 11개 기록 −0.60 %p, 단순 예측보다 −1.02 %p). AI 예측은 0.2 s 정도 앞만 단순 예측보다 낫다. 그런데 지령은 결정 뒤 0.85 s가 지나 적용되고, 남은 약 3 s를 평가에 쓴다. 이번 결과에서는 **예측 정확도가 병목**이다.
3. 그림자 R 제한은 결정의 53~77 %를 막았지만, 전체 기록의 비틀림을 지키지 못했다(고베). 제한은 예측 입력으로 계산하므로, 예측이 틀리면 보호도 틀린다. 그림자 R은 감시·비교 도구이며 무악화를 보장하지 않는다.
4. 개발 3사건에서 보인 작은 AI 추가 기여는 11개 기록으로 넓히자 사라졌다. 사건 수가 적고 결정 시각에 민감해, 통계적 우수성이나 일반화를 주장하지 않는다.
