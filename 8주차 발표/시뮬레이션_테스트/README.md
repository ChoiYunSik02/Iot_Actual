# 8주차 시뮬레이션·테스트 결과 정리 (박정주 · 최윤식)

IOT 액추에이터 — 30층 편심 건물 + 회전형 반능동 TLCD(RS-TLCD) 제어. 8주차에 한 시뮬레이션과 테스트를 한 곳에 모았습니다.
발표자료는 `../발표자료/`(v19 최종본), 대본은 `../대본/`에 있습니다. 이전 버전(v10~v18 등)은 올리지 않았습니다.

> **읽는 법.** 아래 수치는 모두 이 폴더 안 문서(`*.md`, 결과 csv)에서 가져왔습니다. 저감률은 "무제어 대비 6지표(X·Y·비틀림의 최대값·RMS) 평균 저감률"이고, `R`은 원문(Fu et al. 2025)의 제어 규칙, `%p`는 R과의 차이입니다. 모델이 서로 다른 실험의 숫자는 직접 비교하지 마세요(각 절에 표시).

## 2. 원문 재현 (`reproduction_v2`, `reproduction_v2b`)

대상 논문: Fu et al. (2025), *Journal of Building Engineering* 103, 112205. 원문 표 2의 15기록, 원문 표 4~6 전체를 옮겨 대조했습니다. 원문 문장을 문자 그대로 읽은 해석을 우선 시험했고, 근거 없는 보정 계수는 쓰지 않았습니다.

| 조합 | 응답 평균 오차 % | 6지표 평균 저감률 (우리 / 원문) | 차이 %p |
|---|---|---|---|
| 무제어 | 2.47 | — | — |
| 수동 TLCD (D0) | 3.97 | 14.31 / 15.99 | −1.69 |
| S-TLCD (D0) | 5.51 | 15.98 / 16.09 | −0.11 |
| RS-TLCD D0·A | 7.90 | 15.81 / 18.74 | −2.93 |
| RS-TLCD D0·B | 8.59 | 15.33 / 18.74 | −3.41 |
| RS-TLCD D0·C | 8.23 | 15.60 / 18.74 | −3.14 |

- S-TLCD는 평균은 거의 같지만 기록별 차이가 −5.75 ~ +2.66 %p라서, 평균이 맞는다고 기록 단위 재현이 됐다고 볼 수 없습니다.
- 원문의 "RS가 S보다 낫다"(+2.66 %p)는 어느 해석에서도 재현되지 않았습니다(우리 RS − S = −0.17 ~ −0.65 %p). 차이는 주로 X 방향입니다.
- 무제어에서 Chi-Chi 1기록의 RMS가 크게 어긋납니다(원문이 150 s 기록을 잘라 썼다는 추정, 확정 아님).
- 지연 0에서 새 시뮬레이션 층(`sim_layer.py`)과 기존 D0·A 구현(`rs_ref.py`)을 비교: 응답 시간 이력 최대 절대차 0.0, 결정 1,016건 일치, 6지표 평균 저감률 15.811 %.
- 자세한 표·해석: `reproduction_v2b/07_원문대비_오차확정.md`, `reproduction_v2/00_GPT_검토요청_원문재현v2.md`. 이 표는 재현 수준의 기록이며 통과·실패 기준을 사후에 만들지 않았습니다.

## 3. 장치별 상한 시험 — 어느 액추에이터를 미리 움직여야 하나

한 장치만 "미래를 아는" 조건으로 바꾸고 나머지는 원문 규칙으로 두었습니다(재현 모델 D0·A, 15기록, R = 15.81 %). 실제로는 불가능한 참고 실험입니다.

| 바꾼 장치 | 평균 | R 대비 |
|---|---|---|
| 펌프: 원문 규칙이 2.6초 뒤 낼 진동수를 지금 적용 | 15.95 % | +0.14 %p |
| **회전판: 다음 2.6초의 주 진동 방향을 지금 적용** | **18.87 %** | **+3.06 %p** |
| 회전판 45° 고정 | 16.73 % | +0.92 %p |
| 밸브: 1초 대신 매 스텝 판단 | 16.60 % | +0.79 %p |
| 세 장치 모두 선행 + 지연 없음 | 19.78 % | +3.97 %p |

펌프는 조절 범위가 0.320~0.354 Hz(±5 %)로 좁아 진동수를 완벽히 예측해도 이득이 작습니다. 그래서 AI의 예측 대상을 회전판 목표각으로 정했습니다.

## 4. 회전각 예측 AI (`8주차_회전각AI_진행기록.md`, `angle_ai_v1/`, `angle_ai_simulink/`)

- 설계: 입력 특징 13개 → MLP(32, 32) → 다음 2.6초의 최대 변위 방향(0~90°). 펌프·밸브·회전 속도는 원문 그대로. 학습은 논문 15기록과 겹치지 않는 8개 지진(회전 증강), 시험은 논문 15기록.

| 정책 | 15기록 평균 | R 대비 |
|---|---|---|
| R | 15.81 % | — |
| 비학습 1.3초 방향 규칙(최선) | 16.46 % | +0.65 %p |
| AI (시드 0, 사전 고정 최종) | 17.51 % | +1.70 %p (12/15 기록) |
| AI 시드 0~4 | 16.57~17.51 % | 평균 +1.19 %p |
| 참고: 미래 정보 LEAD | 18.84 % | +3.03 %p |

- **사건 동일 가중 평균(4사건):** R 15.95, AI(시드 0) 16.44(+0.48 %p). 시드별 사건 평균 AI−R은 +0.48, −0.89, +0.33, +0.19, +0.15(평균 +0.05).
- 비틀림: θmax가 R보다 나빠진 기록 8/15(최악 −2.32 %p).
- 해석 주의: 방향 예측 오차(지진 단위 교차검증 MAE 13.2°)가 직전 방향 유지(12.0°)보다 낫지 않았고, 이득 일부가 "덜 극단적인 각도 운용" 효과와 겹칠 수 있습니다. 15기록은 가중치 학습에는 안 썼지만 개발 중 반복 사용했으므로 최종 독립 시험이 아닙니다. 판단 주기 2.6초·회전 속도 30°/s만 반영했고 센서·계산·통신 지연은 없습니다.
- **MATLAB/Simulink 확인:** `angle_ai_v1/run_angle_ai_check.m`(R2026a)은 R·AI·비학습 모두 15.81 / 17.51 / 16.46 %로 Python과 일치, `angle_ai_simulink/rs_tlcd_angle_ai.slx`는 스크립트와 최대 상대차 3.8×10⁻⁸ %. 이는 구현 일치 확인이지 원문 수치 일치나 실제 건물 성능 보장이 아닙니다.

## 6. 기존 점수망 AI 대조 (`week08_state_delay_pilot_v2/`)

후보를 점수망으로 고르는 기존 AI를 같은 후보 수의 비학습 선택(DET3, 무작위 RAND3 5시드)과 고정 시간축에서 비교했습니다(`results/V5_results.md`). **이 실험은 원문 재현 모델(2~5절)과 다른 모델에서 나온 값입니다.**

| 방식 | 11기록·7사건 사건 평균 | 공통 8기록·4사건 사건 평균 |
|---|---|---|
| 점수망 | +5.42 %p | +3.91 %p |
| DET3 (비학습) | +2.43 %p | +2.49 %p |
| RAND3 5시드 평균 | +3.06 %p | +3.95 %p |

- 공통 8기록에서는 점수망(+3.91)이 무작위 후보 선택(+3.95)과 구별되지 않습니다. 11기록의 차이는 포항 기록(+10.94 %p)에 크게 의존합니다.
- 포항 이득은 실제 계산 지연을 넣으면 −0.35 %p로 사라지고, 계산 예산 초과 결정 27회가 모두 포항입니다(이 값은 이전 실험 보고에서 가져온 것이라 이번에 원시 CSV로 재확인하지 않음).
- 점수망 1회 재학습은 개선하지 못했습니다(8기록 평균 +4.34 → +3.44 %p). 최신 코드 감사: `00_latest_code_audit.md`, 프로토콜: `01_protocol.md`.

## 7. 반복 예측 + 지연 고려 예측제어 (`predictive_control_matlab/`)

0.2초마다 4초 앞 지반가속도를 예측하고 계산·전달 지연을 반영해 2.6초마다 후보를 다시 고르는 구조의 MATLAB/Simulink 구현입니다(구조는 폴더의 `README.md`). 용량 문제로 제외한 파일은 11절에 있습니다.

- 관문 G1(환경·기준 재현·Simulink 대조·지연/인과성): 노트북 MATLAB에서 통과, Simulink 대 MATLAB 엔진 응답 오차 0, 지연·인과성 시험 39개 통과.
- 실제 미래 입력을 준 참고 제어기(PREVIEW)는 R보다 +3.8~4.5 %p. 학습한 AI는 개발 3사건 +0.53 %p, 기존 11기록(7사건) −0.60 %p로 목표 +2~3 %p에 미달했고, 단순 예측 대비 추가 이득은 확대 평가에서 −1.02 %p였습니다. 결론: 이번 구조에서는 **예측 정확도가 병목**입니다.
- 근거: `week08_submission/결과요약_GPT용.md`, `final_report_v3.md`, `report/`, `preregistration.md`.

## 8. 발표 v19의 결론과 그 근거 위치

v19(`../발표자료/`)의 핵심은 "회전판을 흔들림 피크마다, 45° 쪽으로 절반 당긴 방향으로 돌리는 규칙"입니다. 발표 본문 기준 수치:

- 원문 규칙 대비 기록 평균 +3.0 %p, 지진별 평균 +2.4 %p, 15개 중 14개 기록·지진 4개 모두 개선, 회전량 17 % 감소.
- 시간에 따른 감소율 끝값: 기록 평균 21.2 % → 25.7 %, 지진별 평균 22.2 % → 25.9 %.
- Y·비틀림 최대값 개선은 작고(Y +1.4, 비틀림 +0.6 %p), 15개 중 8개 기록에서 비틀림 최대값이 원문 규칙보다 나쁩니다.
- "피크마다"라는 아이디어는 AI를 시험하다 발견한 **사후 탐색**입니다.
- AI(방향 예측 v8, 예측제어 모방, 강화학습)는 모두 이 단순 규칙보다 낮았습니다.

**주의:** 이 규칙의 실험 코드와 원자료(노트북 `ai_improvement_v4` 등)는 이 폴더에 들어 있지 않습니다. v19 수치의 출처는 `수치출처목록_v5.md`에, 발표 설명은 `../대본/8주차_발표대본_v19.md`에 있습니다.

## 9. 사용한 비교 기준과 표현 원칙

- "원문보다 개선"이 아니라 "같은 재현 모델의 R 대비"로 말합니다(재현 모델은 원문과 2.9~3.4 %p 차이).
- 결과를 본 뒤 고른 기록·진단은 사후 선택이라고 표시합니다.
- Python–MATLAB–Simulink 일치는 구현 검증이며 원문 수치 대조와 구분합니다.
- 개발 기록으로 반복 평가한 결과는 독립 시험이 아닙니다.
