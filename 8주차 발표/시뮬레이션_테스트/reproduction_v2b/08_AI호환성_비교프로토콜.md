# 기존 AI의 새 재현 모델 호환성 점검과 AI 비교 프로토콜 (개정 2판, 2026-10-31 오후)

이 문서는 8주차 **보강용 개발 실험**의 계획과 첫 단계 결과(R 회귀, 처리량)다. 기존 발표본과 과거 AI 결과는 보존한다. 과거 AI 수치(R 대비 +5.42 %p 등)는 다른 모델의 값이며 새 모델의 성능으로 쓰지 않는다. 이번 실행 범위에 **재학습은 없다**.

## 0. 개정 내용 (GPT 지시 반영)
1. 지연 0 R 회귀 확인과 5번 기록 처리량 측정을 먼저 수행했다(§1, §2).
2. 재학습은 범위에서 제외했다. 가중치와 표준화 통계(μ, σ)는 기존 JSON 그대로 고정한다(§3).
3. "점수망이 약해도 성능이 무너지지 않는다"와 "ALL은 상한"이라는 표현을 삭제했다. FIX-RS와 원문 수동 TLCD는 구분했다(§4).
4. 고정 시간축의 지연값과 실제 계산시간을 구분했고, 실행 순서·대체 지령·동점 처리·예측기·예측 입력을 고정했다(§5).
5. 전이 평가와 재학습 판단은 개발 자료에서만 한다. 독립 시험 정의는 아직 확정되지 않았으며, 확정 전 항목을 목록으로 남겼다(§6).
6. 실행 가능한 범위와 예상 시간을 §7에 적었다.

## 1. 지연 0 R 회귀 확인 (완료)
새 시뮬레이션 층(`sim_layer.py`: 플랜트 / 관측 / R 정책 / 시간축 대기열 / 액추에이터 분리)에서 지연 0으로 R(해석 A)을 돌려, 기존 D0·A 구현(`rs_ref.py`)과 15기록 전체를 비교했다. 두 구현은 이산 행렬(`Plant.disc`)만 공유하고, 관측·판정·대기열·회전 제한·상태 전진 루프는 별개 코드다.

판정 기준(실행 전 고정): 시간 이력 최대 절대차 ≤ 1e-12, 결정 기록의 개수·스텝·종류 일치, κ 완전 일치, 진동수·각도 지령 차이 ≤ 1e-12, 상태 로그 차이 ≤ 1e-12.

| 항목 | 결과 |
|---|---|
| 응답 시간 이력(X, Y, 비틀림, 15기록 전 스텝) | 최대 절대차 0.0 |
| 6지표 | 상대차 0.0 |
| 결정 기록 | 1,016건 개수·스텝·종류 일치, 지령 최대차 0.0, κ 불일치 0건 |
| 1초 간격 상태 로그 | 최대차 0.0 |
| 6지표 평균 저감률 | 15.811 % (기존 D0·A 15.81 %와 같음) |
| 기존 MATLAB A 지표와 Python 기준 구현의 최대 상대차 | 1.2e-11 (기존 r1 대조 결과 그대로) |

15기록 모두 합격(`regress_R.py`, `regress_R_result.json`). 평균값만 맞춘 것이 아니라 기록별 응답·명령·상태를 비교했다. 이 확인은 **새 층이 기존 구현을 그대로 재현한다**는 뜻이며, 원문 일치를 뜻하지 않는다.

## 3. 기존 점수망 고정과 입력 98개 정의
- **고정 대상:** `joint_scorer_seed8401.json`의 가중치·편향과 표준화 통계(μ, σ 각 98개). 시험 자료로 표준화를 다시 맞추지 않는다.
- **점수망 이식 확인:** numpy 순전파(`scorer_port.py`)가 JSON에 저장된 parity_X(50×98)의 출력과 최대 1.2e-16 차이로 일치한다.
- **출력:** J_true/J_true(R) − 1의 예측값. 이 값의 R은 과거 모델의 R이다. 새 모델에서는 후보 순위를 정하는 점수로만 쓰고 절대 의미를 주지 않는다.

**입력 98개의 순서·단위·의미** (`build_state_features.m` 기준, 열 번호는 1부터):

| 열 | 의미 | 단위 | 새 모델에서의 계산 |
|---|---|---|---|
| 1–3 | 최상층 X·Y 변위, 비틀림 | m, m, rad | 같은 상태 순서(X30, 장치 IDX, Y30, 장치 IDY, θ30)에서 읽음 → 가능 |
| 4–6 | 같은 세 자유도의 속도 | m/s, rad/s | 가능 |
| 7–10 | 장치 IDX·IDY 변위·속도 | m, m/s | 가능(두 자유도 장치 모델 사용) |
| 11–19 | 장치 실제 f·θ·κ, 목표 f·θ·κ, 목표 − 실제 | Hz, rad, - | 가능. 새 모델은 펌프가 즉시 적용되어 f 목표 − 실제가 0 |
| 20–25 | 관측 나이, 예측 나이, 적용 격자까지 시간, 대기 지령 수, 펌프 램프 남은 시간, 회전 남은 시간 | s, 개 | 가능. 램프 남은 시간은 새 모델에서 항상 0 |
| 26–29 | 마지막 보낸 지령 f·θ·κ, 가장 이른 대기 지령까지 시간 | Hz, rad, -, s | 대기열 층에서 계산 → 가능 |
| 30–37 | 누적 최대·제곱합(X·Y·비틀림), 그림자 R 비틀림 제곱합·최대 | m, rad 등 | 그림자 R을 같은 관측 시각에 병행 계산해야 함 |
| 38–85 | 지반 예측 요약: 0.5 s 8구간 × (X·Y 각 평균, RMS, 최대 절댓값) | 예측기 출력 단위 | **기존 예측 LSTM 출력(fcv)이 필요** — 미이식 |
| 86 | 예측 유효 | 0/1 | 예측기 상태 |
| 87–98 | 후보 f·θ·κ, 후보 − 현재 지령, 마스크 3개, isR, isHold, 빠른 결정 | Hz, rad, - | 후보 생성기에서 계산 → 가능 |

**표준화 통계에서 확인된 것(학습 통계 그대로):**
- 열 20(관측 나이)과 열 24(펌프 램프 남은 시간)는 학습 자료에서 상수 0이다(σ에 하한 1이 들어감). 새 모델에서도 0이므로 이 두 열의 분포 이탈은 없다.
- 그 밖의 열은 σ ≥ 0.001이다. 예: 열 1 σ = 0.035 m, 열 13(실제 κ) μ = 0.51.

**입력 분포 이탈 보고 계획:** 새 모델 개발 자료에서 만든 98개 입력에 대해 열마다 학습 μ·σ 기준 표준화 값의 분위수와 |z| > 3 비율을 **측정해 보고만** 한다. 이 값으로 표준화를 바꾸지 않는다. (입력 생성기 이식 후 가능, 현재 미실시)

## 4. 비교군 정의
| 이름 | 정의 |
|---|---|
| U | 무제어 |
| 원문 수동 TLCD | 원문 재현 2단계 수동 TLCD 모델(07의 "수동 D0"). 원문 표 4의 비교 대상 |
| FIX-RS | RS 장치 모델(두 자유도) 안에서 θ = 0, κ = 0.4, f = 0.3373 고정. 장치 모델이 다르므로 **원문 수동 TLCD와 같지 않다**. 제어 효과를 같은 장치 모델 안에서 분리하는 용도 |
| R | 원문 식 10~13 규칙(해석 A가 주 조건) |
| AI | 점수망 상위 3개 + 유지 + R을 새 모델 내부 예측으로 평가, 비틀림 제약, 해당 없으면 R |
| DET3 | 학습 없는 비교군. 현재 지령에서 이동량이 가장 작은 3개 + 유지 + R |
| RAND3 | 학습 없는 비교군. 무작위 3개 + 유지 + R, 시드 5개(8401, 104729, 1299709, 15485863, 179424673) |
| ALL | 모든 후보를 같은 내부 예측기로 평가해 고르는 비교군 |

ALL은 계산량이 큰 비교군이며 **상한이 아니다**. 내부 예측기가 실제 미래와 같다고 보장되지 않으므로, ALL이 AI보다 낮을 수도 있다. 점수망의 역할은 DET3·RAND3·ALL과의 차이로만 해석하고, 사전에 결과를 가정한 문장은 쓰지 않는다.

## 5. 시간축·실행 규칙 (모든 후보 선택 비교군에서 동일, 실행 전 고정)
- **지연값과 계산시간의 구분:** 고정 시간축의 지연값은 모델 **설정값**이다(기존 [0.27, 0.22] s: 느린·빠른 결정). 실제 계산시간은 따로 측정해서 보고한다. 과거 MATLAB 측정(95번째 백분위, 16코어)은 R 0.8 ms, 선택 C1 0.50 s, 선택 C2 1.42 s이며, 이 값은 예산 0.27 s·0.22 s보다 크다. 따라서 고정 시간축 결과는 "예산 안에 계산이 끝난다고 가정한 시나리오"이며 실시간 실행 가능성의 주장이 아니다. 새 구현의 계산시간은 예측기 완성 후 다시 측정한다.
- **실행 순서(한 스텝 안):** 관측 → 느린 결정 → 대기열에서 도착한 지령 적용 → 회전 갱신 → 빠른 결정 → 도착 지령 적용 → 이산화 선택 → 상태 전진. 지연 0 회귀에서 확인한 순서와 같다.
- **대체 지령:** 지령이 마감까지 도착하지 않으면 그 결정 시각의 R 지령(관측 시각 상태로 계산)을 쓴다. 모든 비교군에 같다.
- **동점 처리:** 후보 색인은 (유지, R, f 오름차순, 각도 오름차순, κ 오름차순)으로 고정한다. 예측 비용이 같으면 낮은 색인을 고른다. DET3의 이동량 동점도 같은 색인 순서다. RAND3은 같은 색인 목록에서 시드로 비복원 추출한다.
- **예측기·예측 입력:** AI, DET3, RAND3, ALL이 같은 내부 예측기(새 모델 4 s 롤아웃)와 같은 지반 예측 입력(같은 예측기 객체, 같은 갱신 시각)을 쓴다. 지반 예측 모델은 기존 LSTM 가중치를 고정해서 사용한다(이식 미완료).
- **비틀림 제약:** 예측 구간에서 R의 그림자 비틀림 최대·RMS보다 나빠지는 후보는 모든 선택 비교군에서 같은 규칙으로 제외하고, 남는 후보가 없으면 R을 쓴다.

## 6. 평가 자료와 판정 (개발과 독립 시험의 분리)
- **개발 자료:** 원문 15기록(모델 설정 선택에 이미 사용) + 합성 지진 검증 자료. 전이 평가, 점수망·비교군 비교, 재학습 필요 여부 판단은 **여기서만** 한다. 포항·경주·El Centro도 반복 분석했으므로 개발 자료로 분류한다.
- **독립 시험:** 최종 정책(가중치, 후보 정의, 선택 규칙, 지연 조건, 비틀림 기준, 집계 방식, 코드 해시)을 **동결한 뒤** 한 번만 수행한다. 이전 판에 있던 새 사건 선정 기준은 **예시**였으며 확정이 아니다. 독립 시험 전에 아래를 문서로 확정하고 해시를 남긴다.
  1. 대상 사건 범위(데이터베이스, 지진 규모·거리·성분 조건)
  2. 선정 순서(정렬 키와 몇 번째까지)
  3. 동점 처리
  4. 자료 누락·성분 결함 처리와 대체 규칙(결과를 보지 않고 적용)
  5. 제외 규칙(이미 분석한 사건 목록)
- **집계와 지표:** 6지표(Xmax, Xrms, Ymax, Yrms, θmax, θrms)의 저감률. 비교량은 기록별 (AI − R) 평균 차이(%p). 원문 15기록은 기록 평균과 사건 평균(사건 4개 동일 가중)을 함께 보고한다.
- **비틀림 기준:** 기록마다 AI의 비틀림 최대·RMS 저감률이 R보다 낮으면(수치 여유 1e-9) 위반 1건. 위반 수와 최악값, U 대비 악화 기록 수를 따로 보고한다.
- **판정 문장:** 결과를 본 뒤 고르지 않는다. 독립 시험에서 AI − R, AI와 DET3·RAND3 최대값의 차이, 비틀림 위반 수를 그대로 보고한다. 목표 수치는 두지 않는다.

## 7. 실행 가능한 비교 범위와 예상 시간
**현재까지 갖춘 것:** 새 시뮬레이션 층(지연 0 R 일치), 점수망 이식(parity 일치), 롤아웃 프로토타입. **아직 없는 것:** 98개 입력 생성기 이식, 지반 예측 LSTM 이식(이 컨테이너에는 torch가 없음), 후보 생성기, 비틀림 제약이 있는 선택 로직, 입력 분포 이탈 측정. 비교군 실행은 이것들이 끝나야 시작할 수 있다.

**처리량에서 외삽한 하한 추정** (§2 측정값 기반, 이 컨테이너 단일 프로세스, 5번 기록의 느린 결정 약 15회·빠른 결정 약 25회로 가정, 한 결정당 평가 후보 수는 AI·DET3·RAND3 5개 / ALL은 느린 결정 46개·빠른 결정 5개):

| 실행 | 5번 기록 1회 | 15기록 1회 (지속시간 배수 약 18.7) |
|---|---|---|
| R | 0.7–1.7 s | 11–27 s |
| AI, DET3, RAND3(시드 1개) | 약 4–16 s | 약 1.3–5 min |
| ALL | 약 15–60 s | 약 5–19 min |

- 모델·지연 조건 한 쌍(선택 비교군 7회 + ALL 1회) 15기록: 약 14–54 min (단일 프로세스). 2코어 병렬이면 절반 안팎.
- 모델 4개(D0·A, D5·A, D0·B, D0·C) × 지연 2개(0, 고정 시간축) = 8쌍: 약 2–7 h(단일), 1–3.6 h(2코어).
- **이 추정은 하한이다.** 지반 예측 모델, 98개 입력 생성, 비틀림 제약 계산을 포함하지 않았다. 해당 요소를 이식한 뒤 같은 방식으로 다시 측정해서 갱신한다. 차가운 캐시 값은 후보별 expm 비용이 모두 새로 드는 경우라 보수적이다.
- **권장 순서:** 주 모델 D0·A, 지연 0, 15기록으로 먼저 AI·DET3·RAND3·ALL을 돌려 전이 평가를 한다(추정 14–54 min). 민감도 모델과 고정 시간축은 그다음에 한다.
