# 01 프로토콜 — 비학습 대조군 고정 시간축 비교 (실행 전 고정, 2026-10-31)

새 학습 없음. 기존 모델·발표본·원시 결과는 덮어쓰지 않는다(새 태그 `V5_*`만 추가). 모든 기록은 개발 평가이며 독립 시험이 아니다.

## 1. 질문
기존 점수망(joint_scorer_seed8401)의 top-3 선택이 같은 후보 수의 비학습 선택보다 폐루프에서 나은가? (AI 포함 시스템이 R보다 나은 것과 별개)

## 2. 고정 조건 (모든 방식 동일)
- 코드: `ai_improvement_v4/predictive_control_matlab`(동결 해시 `b_retrain/frozen_sha256.txt`). 바꾼 파일은 `override/selector_step.m` 하나(det3 분기와 함수 `jmove_det3` 추가, 다른 줄 변경 없음).
- 후속동작 `one_action_R`, 고정 시간축 예산 느림 0.27 s / 빠름 0.22 s, 파형 예측기 torch_pilot8_seed8401(예측 입력), 후보 집합·물리 필터·그림자 R 비틀림 제한·비용·이동 항 동일, 이상적 상태정보 동일.
- 평가: 기존 11개 개발 기록(공통 8기록 + El Centro·포항·경주), 사건 7개.
- 느린 결정: 후보 풀(R·유지 제외)에서 3개를 고르고 유지·R을 항상 포함해 5개를 물리 모델로 평가. 빠른 결정(밸브만)은 후보가 R·유지 외 2개뿐이라 모든 방식이 전부 평가한다(선택 규칙의 영향 없음).
- 실제 미래 입력은 어떤 방식의 선택에도 쓰지 않는다(`diag_true=false`).

## 3. 방식
| 태그 | 설명 |
|---|---|
| V5_SCORER_REF | 기존 점수망 top-3(같은 세션 재실행: 계산시간 비교용. 기존 V4_FOLLOWUP_R과 결과 일치를 확인) + R |
| V5_DET3 | 결정론적 비학습 top-3: 후보 풀을 이동 비용 `(|Δf|/f범위 + |Δθ|/θ범위)/2`(현재 장치 상태 기준, `filter_and_apply_joint_action`의 이동 항과 같은 식) 오름차순으로 정렬, 동점은 후보 생성 순서(안정 정렬). 학습 모델·예측 파형·미래 정보 미사용 |
| V5_RAND3_S1…S5 | 고정 시드 무작위 top-3(Park–Miller LCG, 풀에서 비복원 3개). 시드 5개: 8401, 104729, 1299709, 15485863, 179424673 (결과 보기 전 고정; 8401은 기존 V4_B_RAND3 재현 확인용) |
| R | 기존 V4_FOLLOWUP_R의 R(같은 세션 V5_SCORER_REF의 R과 일치 확인) |

## 4. 보고 지표
R 대비 6지표 평균 저감률 차(%p): 기록 평균, 사건 동일 가중 평균, 개선 기록 수; 비틀림 위반(최대·RMS 중 R보다 나쁨, 1e-9 초과): 위반 기록 수·위반이 있는 사건 수·최악 크기; 사건별 차이; 선택 계산시간(런타임 로그). 공통 8기록과 11기록을 따로 보고한다.

## 5. 판정 규칙 (결과 보기 전 고정)
- "점수망 학습 기여 확인": 11기록에서 점수망의 사건 평균 개선이 DET3와 무작위 5시드 평균을 모두 넘고, 무작위 5시드 [최소, 최대] 범위의 최댓값도 넘으며, 위반 기록 수가 비교 방식보다 많지 않을 때만 사용.
- 위가 아니면 "점수망 학습 기여 미확인"으로 보고. 부분적으로 만족하면 만족한 항목과 아닌 항목을 그대로 적는다.
- 이 규칙과 시드, 규칙(det3)은 결과를 본 뒤 바꾸지 않는다. 다른 시드·규칙 추가 탐색을 하지 않는다. 5시드 변동은 불확실성의 일부일 뿐 통계적 유의성으로 말하지 않는다.
- 실측 계산시간은 실행마다 달라 한 값을 대표로 쓰지 않는다. 고정 시간축 제어 결과는 계산시간에 영향받지 않는다.

## 6. 작업량 산정
기존 폐루프 로그(`b_retrain/closed.log`, 같은 11기록·같은 코드 두 번 실행)에서 J-AI 한 정책당 11기록 합계 159.3 s와 158.4 s(기록별 5–34 s). 이번 7개 실행(점수망 재실행, DET3, 무작위 5시드) ≈ 7 × 160 s ≈ 19분(점수망 재실행에는 R도 포함). 학습 없음.

## 7. 51.5 %·44 %·47 % 수치의 분모와 정의 (이전 보고의 정정 포함)
출처: `data/joint_teacher_v4.csv`(1,568 상태, 34,990행, 느린 결정 768 + 빠른 결정 800). 후보 = R·유지 행 제외. "제한 만족" = `Qc ≤ QR(1+1e-12)` 그리고 `Mc ≤ MR(1+1e-12)` 그리고 `J_true` 유한. Qc = 그때까지의 누적 비틀림 제곱합 + 예측 구간 비틀림² 합, Mc = 그때까지 비틀림 최대와 예측 구간 |비틀림| 최대 중 큰 값, QR/MR = 같은 관측 시각 그림자 R의 대응값. 모두 실제 미래 입력으로 계산한 teacher 라벨.
| 집합 | 분모(상태) | 제한 만족 후보 ≥1 | 비용 oracle top-3에 만족 후보 | 무작위 top-3 기대값 |
|---|---|---|---|---|
| 전체(이전 보고의 51.5/44/47) | 1,568 | 808 (0.515) | 694 (0.443) | 0.467 |
| val | 320 | 172 (0.537) | 151 (0.472) | 0.497 |
| **느린 결정만 (top-3이 실제 적용되는 집합)** | 768 | 424 (0.552) | 310 (0.404) | 0.454 |
| 빠른 결정 | 800 | 384 (0.480) | 384 (0.480) | 0.480 |
- 정정: 이전 보고의 44 %·47 %는 빠른 결정(후보 2개, top-3 무의미)을 섞은 값이다. top-3이 적용되는 느린 결정만 보면 oracle 40.4 %가 무작위 45.4 %보다 낮다. 결론의 방향은 같다.
- oracle = 실제 미래 비용 J_true 오름차순 상위 3개. 무작위 기대값 = 비복원 추출의 정확한 확률. 이 값들은 학습 라벨 분석이며 폐루프 성능이 아니다.
