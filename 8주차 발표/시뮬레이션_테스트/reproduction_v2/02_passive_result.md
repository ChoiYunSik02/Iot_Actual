# 원문 재현 v2 — 2단계: 수동 TLCD (2026-10-31)

1단계 채택 조건(식 19 문자 그대로, 성분별 35 cm/s² 정규화, 기록 길이 그대로)에 X·Y 수동 TLCD 2기를 붙였다.
코드: `tlcd3.py`(식 15~22를 글자 그대로 조립한 92자유도 모델), `sweep3.py`(해석 변형 비교), `paper_tables.py`(원문 표 4~6 전 열). 결과: `passive_vs_paper.csv`.

## 원문 표 전사 검증
표 4~6에서 옮긴 값으로 표 7의 15기록 평균 저감률을 다시 계산하면 Passive·S-TLCD는 18개 값이 0.02 %p 이내로 일치.
RS-TLCD는 Y RMS 17.82 대 표 7 18.00, 비틀림 RMS 15.82 대 16.03으로 원문 표 사이에 작은 불일치가 있다(전사 오류가 아니라 원문 내부 차이로 판단; 표 6 3번 행은 원본 이미지로 재확인해 수정함).

## 장치 값 (원문에서 유도)
- m_d = 463,178 kg(1차 모드 질량의 2 %), f = 0.3373 Hz → L = 2g/ω² = 4.368 m, k_d = m_d ω² = 2.080e6 N/m. 식 20의 k = 2 m_d g / L과 같은 식이므로 m_d = ρ Av L로 보고 Av = 106.0 m², Ah = Av/λ = 459.0 m²(λ = 0.231).
- δ = δ1 + λ²δ2 = 1.443 (κ = 0.4, 식 5·6).

## 해석 변형 비교 (15기록 × 6지표 응답의 평균 |상대오차|)
| 감쇠 행렬 구성 | 장치 감쇠 계수 | 평균 오차 |
|---|---|---|
| Rayleigh를 장치 포함 전체 M, K에 적용 | 식 7: ½ρAhδ | **3.97 %** |
| 같음 | 식 24: ½ρ(Av²/Ah)δ | 6.09 % |
| Rayleigh를 건물에만 적용(장치 감쇠는 비선형 항만) | 식 7 | 4.84 % |
| 같음 | 식 24 | 11.0 % |
| 장치 강성을 비틀림 결합(K_xθ = K_x e_y)에 포함 | 식 7 / 식 24 | 4.94 / 6.83 % |
감쇠 속도를 상대속도 대신 장치 절대속도 크기로 쓰는 변형은 차이 0.1~0.3 %p로 판별되지 않음.

채택: Rayleigh를 장치 포함 전체 시스템에 적용(원문 "C는 같은 방식으로 Rayleigh 감쇠로 구성하고 c_dx, c_dy를 더한다"의 문자 그대로 해석) + 식 7 계수.

## 채택 조건 결과
- 6지표 평균 저감률: 우리 14.31 %, 원문 15.99 % (차이 −1.7 %p). 이전 재현(8기록)의 −3 ~ −10 %p보다 크게 줄었다.
- 기록별·지표별 저감률 90개의 상관 0.981. 부호와 경향이 기록 단위로 일치(예: 10번 Y 최대 우리 −7.6 / 원문 −8.0 %, 15번 Y 최대 −2.0 / −3.5 %).
- 남은 차이는 체계적: 우리 저감률이 Y·비틀림에서 2~4 %p 낮다(장치 효과가 약간 작음).

## 주의
- 계수 크기를 더 조절하면(식 7 × 2) 평균 오차가 약간 줄지만, 원문에 근거 없는 보정이므로 채택하지 않았다.
- 남은 −1.7 %p의 원인 후보: 장치 위치(질량중심 가정), 적분법, 표에 없는 κ·λ 외 장치 치수.
