# 주간보고서 PPT 생성

IOT 액추에이터 팀(박정주·최윤식)의 주간보고서를 1주차 발표자료에서 추출한
디자인 시스템 그대로 생성합니다.

## 작업 순서

1. **연구 맥락 확인** — `tlcd-brief` 스킬의 `references/research-plan.md`를 먼저 읽어
   현재 주차와 진행 단계를 파악합니다. 사용자가 주차를 말하지 않았다면 물어봅니다.

2. **디자인 규격 로드** — `references/design-tokens.md`를 읽습니다.
   색상·폰트·좌표를 임의로 바꾸지 마세요. 1주차 자료와 일관성이 깨집니다.

3. **내용 설계** — 발표 시간을 먼저 확인합니다.
   - 시간 미지정 시 물어볼 것
   - 분량 기준: **1분당 약 1.3장**, 대본은 **분당 280자**
   - 예) 17분 → 22장 내외, 대본 총 4,400자 내외

4. **생성 스크립트 작성** — `scripts/deck.py`를 import 해서 내용만 정의합니다.
   헬퍼를 다시 구현하지 마세요.

5. **검증** — 저장 후 반드시 `scripts/validate.py`를 실행합니다.
   텍스트 넘침·표 셀 넘침·발표 시간을 자동 점검합니다.

## 스크립트 사용법

```python
import sys; sys.path.insert(0, r'<이 스킬의 scripts 경로>')
from deck import *

prs = new_deck()

s = light()                      # 밝은 배경 슬라이드
head(s, 'BACKGROUND', '주제 변경 배경')
bullets(s, ['첫째 …', '둘째 …', '셋째 …'], y=2.5, tw=6.45)
bar(s, '핵심 판단', '한 줄 결론', sub='보조 설명')
pg(s, 3)
notes(s, '[1:00] 발표 대본 …')

s = dark()                       # 어두운 배경 슬라이드
head(s, 'CONTENTS', '목차', dark=True)
...

save(prs, r'C:\...\보고서_3주차')   # .ppt / .pptx 둘 다 저장, 잠기면 _v2로 회피
```

주요 헬퍼: `light()` `dark()` `head()` `T()` `rr()` `rect()` `circ()` `numdot()`
`bullets()` `bar()` `table()` `cards()` `notes()` `pg()` `save()`

각 인자는 `scripts/deck.py` 상단 docstring에 정리되어 있습니다.

## 반드시 지킬 것

- **파일 형식**: `.ppt`와 `.pptx`를 함께 저장합니다. 교수님 제출용은 `.ppt`.
  실제 내부 형식은 OOXML이며, 진짜 바이너리 .ppt가 필요하면 PowerPoint에서
  "다른 이름으로 저장 → PowerPoint 97-2003"을 안내하세요.
- **파일 잠김**: PowerPoint에서 열려 있으면 `PermissionError`가 납니다.
  `save()`가 자동으로 `_v2` 이름으로 회피하지만, 사용자에게 닫아달라고 알리세요.
- **폰트**: Arial 고정. 한글도 Arial로 지정합니다(1주차 자료와 동일).
- **슬라이드 크기**: 12188952 × 6858000 EMU (13.33 × 7.5 인치). 변경 금지.
- **콘솔 인코딩**: Windows에서 `PYTHONIOENCODING=utf-8`을 붙여 실행하세요.
  안 그러면 `cp949` 인코딩 오류가 납니다.
- **참고문헌**: 최근 4년(2022년 이후) 논문만 씁니다. 지도교수가 오래된 문헌을
  선호하지 않습니다. 목록은 `tlcd-brief` 스킬의 `references/papers.md` 참조.

## 검증 통과 기준

- 텍스트 넘침 0건, 표 셀 넘침 0건
- 슬라이드 밖으로 나간 도형 없음 (표지 장식 원은 의도된 예외)
- 대본 총 시간이 목표 시간의 80~100% 범위
