## 4. test 세트 사전 등록 (실행 전 고정)

이 절은 test 결과를 보기 전에 커밋한다. 결과가 나쁘다는 이유로 규칙, 기록, 지표, 기준을 바꾸지 않는다.

### 고정 조건
- 모델: 8주차 재현 모델 D0·A (`reproduction_v2b/sim_layer.py`), 지연 0
- 전처리: 원문 15쌍과 같다. 각 성분을 최대 가속도 0.35 m/s²로 맞추고(`tlcd.load_records`와 같은 방식), 입력 dt를 그대로 쓴다.
- 성분 배정: NGA 파일의 첫 번째 수평 성분을 X, 두 번째를 Y로 둔다(`record_manifest.csv`의 h1·h2). 회전 증강은 하지 않는다.
- 피크 규칙: `peak_rule.py`의 `Peak(dt)` 기본값 (r = √(x²+y²), 30% 문턱, 45° 쪽 0.5 당김). 코드는 이 계획과 함께 커밋된 버전이다.

### 비교군
| ID | 내용 | 역할 |
|---|---|---|
| U | 무제어 | 저감률 분모 |
| R | 원문 규칙 | 주 기준 |
| FIX45 | 회전판 45° 고정, 펌프·밸브는 원문 | 아무 판단 없이 얻는 이득 (8주차 +0.92%p) |
| PEAK | 피크 규칙 (동결) | 주 시험 대상 |
| PEAK_maxabs, PEAK_pull1 | 8주차 변형 (r = max(\|x\|,\|y\|) / 피크 순간 방향 그대로) | 보조. 순위가 바뀌는지 확인용 |

> 11/04 정정 (test 실행 전): 처음에 "PEAK_pull0"이라고 쓴 변형은 식 θ* = 45° + pull(φ − 45°)에서 45° 고정과 같아서, 의도한 "순간 방향 그대로"인 pull = 1로 바꿨다. 원문 15쌍에서 pull1의 비틀림 RMS 최악값은 −7.61%p로 v19 11쪽과 같다.
> FIX45는 0°에서 출발해 30°/s로 45°에 도달한다. 원문 15쌍 16.68%로, 8주차 상한 시험 표의 16.73%와 0.05%p 다르다(8주차는 출발 각도를 바로 45°로 뒀을 가능성). 판정에 쓰는 비교군이므로 이 정의로 고정한다.

### 지표와 집계
- 6지표: X·Y 변위와 비틀림각의 최대값·RMS. 무제어 대비 저감률 r = 100(1 − 응답/U)
- 기록마다 6지표 평균을 낸다. 사건마다 기록을 평균한 뒤, 사건을 같은 가중치로 평균한다.
- **주 효과량: 사건 동일 가중 ΔS = PEAK − R (%p).** 사건 단위 paired bootstrap 10,000회(seed 8500)로 95% 구간을 낸다.
- 함께 보고: FIX45 대비 차이, 개선 사건 수와 기록 수, 비틀림 최대·RMS가 R보다 나빠진 기록 수와 최악값, 회전량, 6지표별 차이
- 그룹별(설명용, 판정에 쓰지 않음): 원거리 / 근단층 펄스 / 근단층 비펄스

### 판정 (미리 정한 문장)
| 결과 | 발표 문장 |
|---|---|
| ΔS 95% 구간 하한 > 0 이고 PEAK > FIX45 | "새 지진 12개 사건에서도 R보다 나았다" |
| ΔS 평균 > 0 이지만 구간이 0을 포함 | "개선 경향은 있지만 12개 사건으로는 확정할 수 없다" |
| ΔS 평균 ≤ 0 | "원문 15쌍의 개선은 새 지진에서 유지되지 않았다" |
| PEAK가 R보다 낫지만 FIX45보다 낫지 않음 | "개선은 피크 판단이 아니라 45° 쪽 운용에서 나온다" |

비틀림은 판정과 따로 보고한다. 비틀림 최대가 R보다 나빠진 기록이 하나라도 있으면 "비틀림 보호는 달성하지 못했다"고 쓴다.

## 5. 잡음·지연 민감도 (dev 기록만)

test 세트는 4절에서 한 번만 쓴다. 민감도 시험은 원문 15쌍과 dev 18쌍으로 한다.

- 지연: 결정부터 회전판 지령 적용까지 0, 0.1, 0.2, 0.5, 1.0 s (`sim_layer.simulate`의 `delay_slow`). R에도 같은 지연을 준다.
- 잡음: 옥상 변위 측정값에 백색 잡음을 더한다. 잡음 RMS는 신호 RMS의 1, 5, 10%이고 시드는 5개다. 피크 판정은 잡음에 약할 수 있으므로 거짓 피크 개수도 센다.
- 보고: 지연·잡음별 ΔS(PEAK − R)와 피크 개수. 이득이 0이 되는 지연을 "허용 지연"으로 제시한다. 이것은 연구 브리프 연구축 ②(제어 지연)와 연결된다.
- 잡음 때문에 성능이 무너지면 필터나 문턱을 바꾼 규칙은 **새 버전**으로 분리한다. 그 버전은 test에서 다시 평가하지 않는다.

## 9. AI 밸브 제어기 사전 등록 (11/08, 밸브 상한 결과와 신경망 결과를 보기 전에 고정)

- 질문: 현재 측정값만 쓰는 신경망이 밸브를 매 스텝 연속값으로 조절하면 LP_V보다 응답을 더 낮출 수 있는가.
- 구조(NN_V): 회전판과 펌프는 LP_V 그대로다. 밸브 감쇠는 log c = log c(원문 3단계 규칙) + 신경망 보정이고 kappa 0.1~0.8 범위로 자른다. 신경망 출력이 0이면 LP_V와 같다.
- 입력: 원문 밸브 규칙이 쓰는 값(TLCD 상대속도, 옥상 절대가속도, 현재 회전각)과 그 인과 이동평균. 미래 정보는 쓰지 않는다.
- 학습: LP_V의 회전판과 펌프 궤적을 고정한 미분 가능 시뮬레이션으로 6지표 평균을 직접 최소화한다. 2층 32노드, Adam 1e-3, 40 epoch, 각 기록 앞 40 s. 이 값은 고정하고 조정하지 않는다.
- 평가: 개발 62쌍 19사건 사건 빼기 검증. 학습 뒤에는 회전판과 펌프까지 되먹임되는 실제 simulate로 평가한다.
- 채택 기준: NN_V − LP_V 사건 평균 > 0, 사건 단위 95% 구간 하한 > 0, 나아진 사건 수 > 나빠진 사건 수. 셋 다 만족해야 채택한다. 비틀림 최대가 R보다 나빠진 기록 수도 함께 보고한다.
- test2는 이미 1회 썼으므로 쓰지 않는다. 채택되면 62쌍 전체로 다시 학습해 동결하고, 독립 평가는 새 세트(test3)에서 한 번만 한다. 그 전에는 개발 결과로만 쓴다.
