## 1. AI 기반 구조 제어 — 서론 · AI 방식 선택 근거

### 25. ★ 액체 댐퍼 + LSTM 준능동 제어
**Ensemble of long short-term memory recurrent neural network for semi-active control of tuned liquid wall damper**
Wang, Ubertini, Laflamme · *Engineering Structures* 270 (2022) 114771 · **ScienceDirect ✅**
DOI: [10.1016/j.engstruct.2022.114771](https://doi.org/10.1016/j.engstruct.2022.114771)

- 20층 실물 규모 건물 + 분산 준능동 액체 다중 기둥 댐퍼, LSTM 앙상블 제어기 → 수동보다 개선, 전 상태 슬라이딩모드 제어기와 비슷한 성능
- **쓰는 곳:** 서론 "AI를 액체 댐퍼(TLCD 계열) 준능동 제어에 적용한 선행연구". 우리와 차이 = 지진 시작 직후 짧은 판단 시간과 물기둥 포화

### 28. ★ 강화학습 준능동 (국내 저자, MR 댐퍼)
**Development of a Control Algorithm for a Semi-Active Mid-Story Isolation System Using Reinforcement Learning**
Kim, Kim · *Applied Sciences* 13 (2023) 2053 · **오픈액세스 ✅**
DOI: [10.3390/app13042053](https://doi.org/10.3390/app13042053)

- 중간층 면진 + MR 댐퍼, DQN으로 제어 규칙 학습
- **쓰는 곳:** 서론 AI 제어 분류(강화학습). 왜 우리는 강화학습 대신 **지도학습 추정 + 규칙 제어**를 택했는지 설명할 때 비교 대상

### 29. 하이브리드 심층 강화학습 (물리 + 데이터)
**Continuous control of structural vibrations using hybrid deep reinforcement learning policy**
Panda, Chopra, Matsagar et al. · *Expert Systems with Applications* 252 (2024) 124075 · **ScienceDirect ✅**
DOI: [10.1016/j.eswa.2024.124075](https://doi.org/10.1016/j.eswa.2024.124075)

- 데이터 기반 + 물리 기반 RL 정책 결합, 단독 정책보다 우수
- **쓰는 곳:** 서론 — 최신 AI 제어 동향. "물리 지식을 AI에 넣는다" → 우리 **비대칭 손실(물기둥 한계 반영)** 과 같은 방향

## 5. 서론에서 이 논문들을 어떻게 엮나 (초안)

```
① 준능동 TLCD는 효과적 (07 Ocean Eng. 2025, 06 JOBE 2025)
② 중층 건물엔 STLCD 필요 (10 JIPR 2026)
③ AI 기반 구조 제어가 늘고 있음
     - 강화학습: 28 Kim 2023, 29 Panda 2024, 30 Zhang 2023
     - 신경망 제어 · 예측: 25 Wang 2022 (액체 댐퍼), 13 Huang 2023
④ 그러나 근거리 · 펄스형 극한 입력에서 동조 감쇠기는 성능이 떨어짐 (31 Zhang 2025, 27 Farsijani 2025)
⑤ 경보 기반 예측 (14·17·18·20) 은 수 초의 리드타임이 전제 → 근거리에선 0초
⑥ 첫 1초 미만 관측으로 예측하는 연구 등장 (26 AlHamaydeh 2024) — 그러나 지반운동 예측까지만, 감쇠기 설정과 물기둥 한계는 다루지 않음
⑦ 연구 공백 → 본 연구: 경보 없이, TLCD 1/4 주기 안에, AI가 크기를 추정해 밸브를 설정, 과소 예측 벌점으로 포화 방지
```

**AI 방식 선택 논리 (서론 · 방법에 쓸 문장 재료)**
- 강화학습(28·29·30)은 성능이 좋지만 학습이 무겁고, 안전 보장이 어렵고, 결과 설명이 어려움
- 우리는 **지도학습으로 크기 하나만 추정 + 검증된 규칙 제어(Δ-DBG)** → 가볍고(MCU 가능, 34), 설명 가능하고, 틀려도 안전한 쪽으로 유도 가능(비대칭 손실)
- 강화학습은 **향후 연구**로 제시
