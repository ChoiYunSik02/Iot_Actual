# 6주차 피드백 반영 정리 (박정주 · 최윤식)

IOT 액추에이터 — 건물 능동 제진(TLCD), 6주차 발표 후 정리한 자료입니다.

| 위치 | 내용 |
|---|---|
| `교수님_피드백_정리와_7주차_계획.md` | **먼저 읽을 문서.** 교수님 피드백(세기 → 진동수 예측 AI), 우리 해석, 7주차 실험 제안, 논문 작성 방향 |
| `발표자료/` | 6주차 발표 PPT |
| `대본/` | 6주차 발표 대본(수정본, Word) |
| `시뮬레이션_테스트/python_실험코드/` | 6주차 시험 코드와 결과(JSON) — 사용법은 해당 폴더의 `README_6주차_실험.md` 참고 |
| `시뮬레이션_테스트/matlab_교차검증/` | MATLAB 교차검증 (`w6_crosscheck.m`, `ref.csv`, `matlab_result.csv`) |
| `시뮬레이션_테스트/보유기록_데이터/` | 보유 지진 기록 7개(txt)와 출처 설명, 한국 기록 내려받기 스크립트 |
| `시뮬레이션_테스트/보유기록_진동수분석/` | 보유 지진 기록 7개의 주요 진동수 예비 분석 |

`보유기록_진동수분석/rec_freq.py`는 기록 폴더 경로를 인자로 받습니다. (예: `python rec_freq.py ../보유기록_데이터`)
