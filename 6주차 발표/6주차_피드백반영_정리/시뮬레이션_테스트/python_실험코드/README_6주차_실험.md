## 실험 코드 (`실험코드_python/`)
파이썬 + numba로 4~5주차와 같은 지배방정식을 다시 구현한 것입니다 (MATLAB 원본이 아님).
- 모델: 6층 전단건물(1차 0.872 Hz, 모달 질량 1,382 t), 밀폐형 STLCD(물 6.9 t = 모달 질량의 0.5%), 밸브 지연 0.05 s, RK4 dt 2.5 ms, 24 s.
- `sim.py` 시뮬레이터 · `pack.py` 시나리오 묶음 · `cost.py` 비용(종합 점수) · `scen.py` 시나리오 생성
- `x6.py` 공통 함수(펄스 생성, 실행, 지표) · `x6_stage1.py` 단일 펄스 500개 · `x6_stage2.py` 판단 시간·세기 추정 AI(MLP) 학습
- `x6_stage3.py` AI가 밸브를 직접 고르는 경우 · `x6_real.py` 실제 기록(El Centro, 포항, 경주) · `x6_burst.py` 반복 충격
- `x6_table.py`, `x6_more.py` 전략 비교표와 보조 결과 · `ref_dynamics.py` MATLAB 비교용 기준값 생성

실행 예: `python x6_real.py` (기록은 기본적으로 `../../matlab/w5/records/`에서 읽음. 이 폴더(6주차_피드백반영_정리) 안에서 실행할 때는 환경변수 `W5_RECORDS`에 `../보유기록_데이터` 경로를 지정)
필요한 것: Python 3, numpy, numba. 중간 학습 파일(`*.pkl`)은 올리지 않았으므로 `x6_stage1.py` → `x6_stage2.py` 순서로 다시 만들어야 합니다.

## 시험 3종
1. 단일 펄스 500개 (반정현, 0.2~2 g, 주기 0.2~2 s)
2. 실제 지진 기록 84개 (원거리 기록 7성분 × 0.2~1.5 g × 건물 A/B, 진폭을 키워서 사용)
3. 반복 충격 200개 (건물 주기 근처 3~6회, 0.3~1.5 g)

## 주요 결과 (슬라이드 수치와 동일)
- 단일 펄스: 최대 변위 저감 없음(−0.2%). 진동(RMS) 저감 — 고정 7.0%, 규칙 7.4%, AI 7.4%. 한계 초과 — 고정 0%, 규칙·AI 3.5%.
- **AI와 규칙은 제어 효과가 같았음** → AI의 추가 제어 이득은 아직 확인하지 못함. 세기 추정 정확도는 0.1 s 관측창에서만 AI가 더 좋았음.
- 실제 기록: 설계값(ξ=6)은 1 g부터 물기둥 한계 초과(1.0 g 7%, 1.5 g 21%). 세기 정보를 쓰면 0%(정답 세기 기준, 표본 내 평가).
- 반복 충격: 최대 감쇠(ξ=24)에서도 39% 한계 초과.
- 지연: 단일 펄스에서 0~6 s 지연은 진동 저감 7.5~7.8%로 영향이 작았음 (실제 지진·반복 충격으로 일반화 불가).
- MATLAB 교차검증: 건물+장치 방정식 결과가 파이썬과 일치 (옥상 변위 0.0000%, RMS 0.0002%, 물기둥 0.0017% 이내). 센서·제어기·건물 B 강성 저하는 비교에 포함하지 않음.
